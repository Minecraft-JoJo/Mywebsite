统一接口

所有模型长一个样

sklearn 里几十个模型，用法几乎完全相同：

from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.svm import SVC

model = LogisticRegression()      # 1. 建
model.fit(X_train, y_train)       # 2. 训
y_pred = model.predict(X_test)    # 3. 预测
score = model.score(X_test, y_test)  # 4. 打分

换一个模型，只改第一行：

model = RandomForestClassifier()   # 别的都不用动
这套接口是 sklearn 最重要的东西

API 统一意味着：你可以用同一段代码试遍所有模型。

写个循环，把模型列表跑一遍，就知道这份数据该用哪个：

for name, m in models:
    m.fit(X_train, y_train)
    print(name, m.score(X_test, y_test))

换成别的库（PyTorch 之类），每个模型的写法都不一样，这行代码就不成立了。

四种角色

角色核心方法例子
Estimator（估计器）fit所有模型
Predictor（预测器）predict / score分类器、回归器
Transformer（转换器）transform / fit_transformScaler、Encoder、PCA
Meta-estimator（元估计器）接收别的模型当参数Pipeline、GridSearchCV

记住两条规则：

  • 有 predict 的，是模型
  • 有 transform 的，是预处理

两者都有的是少数（比如某些降维后还能分类的）。

fit 到底做了什么

这个名字容易误解。它不只是“训练”，而是“从数据里学出需要记住的东西”。

对象fit 学了什么
StandardScaler每列的均值和标准差
OneHotEncoder每列有哪些类别
SimpleImputer每列的填充值（比如中位数）
PCA主成分方向
LogisticRegression权重 w 和偏置 b

学出来的东西存在带下划线结尾的属性里：

sc = StandardScaler().fit(X_train)
sc.mean_        # 学到的均值
sc.scale_       # 学到的标准差

lr = LogisticRegression().fit(X_train, y_train)
lr.coef_        # 学到的权重
lr.intercept_   # 学到的偏置
下划线结尾是约定

结尾有下划线的属性 = fit 之后才有。没 fit 就访问会报 NotFittedError。

结尾没有的（如 C、n_estimators）= 你设的超参数。

这个约定在调试时特别有用：一眼能看出哪些是学出来的、哪些是你设的。

get_params / set_params

所有 estimator 都能这样读写参数，这是网格搜索的基础：

m = RandomForestClassifier(n_estimators=100)
m.get_params()["n_estimators"]      # 100
m.set_params(n_estimators=300)      # 改成 300

# 等价于构造时传参
RandomForestClassifier(n_estimators=300)

clone：复制一个没训练过的

from sklearn.base import clone

m2 = clone(m)      # 同样的参数，但没 fit 过
m2.fit(X2, y2)

直接 m2 = m 是同一个对象，再 fit 会覆盖。交叉验证和网格搜索内部都用 clone。

怎么知道自己该用哪个

看 y 的类型：

y 是什么任务用
离散类别（0/1、"猫/狗"）分类*Classifier
连续数值（价格、温度）回归*Regressor
没有 y聚类 / 降维*Cluster / PCA

每个算法家族通常成对出现：RandomForestClassifier / RandomForestRegressor，DecisionTreeClassifier / DecisionTreeRegressor。名字后面那个词告诉你用途。
