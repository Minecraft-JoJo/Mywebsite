拓展大全

sklearn 除了前面讲的，还有一大堆模块。这一页按功能分类列全，用的时候当索引。

一、监督学习 · 分类 / 回归

家族分类器回归器一句话
线性LogisticRegression、RidgeClassifierLinearRegression、Ridge、Lasso、ElasticNet基线首选
树DecisionTreeClassifierDecisionTreeRegressor可解释，易过拟合
集成-装袋RandomForest、ExtraTrees同名加 Regressor开箱即用
集成-提升GradientBoosting、HistGradientBoosting、AdaBoost同名加 Regressor表格数据最强

二、无监督

聚类 cluster

类特点
KMeans球形簇，快，要给 k
MiniBatchKMeans大数据集的分批版
DBSCAN密度，任意形状，自动识别噪声
HDBSCAN密度差别大时更好
AgglomerativeClustering层次聚类
SpectralClustering图论方法，处理非凸簇
GaussianMixture软聚类，给每个点的归属概率
Birch层次 + 增量，内存友好
MeanShift自动定簇数，慢
AffinityPropagation自动定簇数，很慢
OPTICSDBSCAN 的变体，对 eps 不敏感

降维 decomposition / manifold

类用于
PCA线性，密集数据
TruncatedSVD稀疏矩阵（文本）
NMF非负数据，可解释性好
FastICA盲源分离
KernelPCA非线性 PCA
t-SNE可视化专用，不能用于新数据
Isomap、LLE、MDS、SpectralEmbedding流形学习，也是可视化
UMAP不在 sklearn 里，要单独装

异常检测

类做法
IsolationForest随机切分，异常点容易被快速孤立
OneClassSVM只用正常样本训练，学一个边界
LocalOutlierFactor基于局部密度
EllipticEnvelope假设数据服从高斯分布

五、组合与流程

类作用
Pipeline串行：上一步输出是下一步输入
FeatureUnion并行：多个转换器结果横向拼起来
ColumnTransformer按列分流
TransformedTargetRegressor对 y 做变换（比如先取 log）
MultiOutputClassifier多标签：每个标签一个模型
ClassifierChain多标签：标签之间有关联时
OneVsRestClassifier多分类当成多个二分类
OneVsOneClassifier两两配对
from sklearn.compose import TransformedTargetRegressor
import numpy as np

# 对 y 取 log，预测时自动还原
m = TransformedTargetRegressor(regressor=Ridge(), func=np.log1p, inverse_func=np.expm1)

七、多分类策略

sklearn 的分类器原生支持多分类，不用手动 OvR。

内部策略：逻辑回归默认用 OvR（可改 multi_class="multinomial"）， 树和随机森林原生多分类，SVM 默认 OvO。

dummyDummyClassifier：随机/多数类基线，用来验证你的模型有没有比瞎猜强
DummyClassifier 别忽略

90% 负类的数据上，模型准确率 0.91 看着不错——但你得知道“全判负”也能到 0.90。

用 DummyClassifier(strategy="most_frequent") 跑一遍，就知道你的模型有没有真的学到东西。
