参数作用常用值

二、保存写出

to_csv —— 最常用

参数作用常用值
path_or_buf目标文件或路径"out.csv"
sep分隔符","（默认）
index要不要写行号False（几乎总是要关）
header要不要写表头True / False
encoding编码"utf-8-sig"（Excel 能开）
columns只写这几列["a","b"]
float_format浮点格式"%.3f"
na_rep缺失值写成什么"" / "NaN"
mode写入模式"w"（覆盖）/ "a"（追加）
date_format日期格式"%Y-%m-%d"
quoting引号策略csv.QUOTE_ALL
# 最常用：不要行号，不要索引
df.to_csv("out.csv", index=False, encoding="utf-8-sig")

# Excel 打开不乱码 ← 关键就是 utf-8-sig
df.to_csv("报表.csv", index=False, encoding="utf-8-sig")

# 浮点只保留 3 位
df.to_csv("out.csv", index=False, float_format="%.3f")

# 缺失值写成空
df.to_csv("out.csv", index=False, na_rep="")
encoding=utf-8-sig 是中文 CSV 的关键

utf-8 存出来的中文 CSV，用 Excel 打开是乱码。

utf-8-sig 会在文件开头加三个字节的 BOM 标记，Excel 就知道这是 UTF-8 了。

代价：某些程序读到开头会多出奇怪字符。纯 Python 内部用就用 utf-8， 要给 Excel 看才用 utf-8-sig。

训练日志：追加写入

训练时每个 epoch 记一行，这是最常见的场景：

import os
import pandas as pd

LOG = "train_log.csv"

for epoch in range(1, EPOCHS + 1):
    loss, acc = train_one_epoch()

    row = pd.DataFrame([{"epoch": epoch, "loss": loss, "acc": acc}])
    row.to_csv(
        LOG,
        mode="a",                             # 追加，不是覆盖
        header=not os.path.exists(LOG),       # 只有第一次写表头
        index=False,
    )
三个参数缺一不可

mode="a"：不加就是覆盖，只剩最后一行。

header=not os.path.exists(LOG)：不加就每次写一遍表头，日志里全是重复行。

index=False：不加会多一列没用的行号。

更好的做法：先收集，最后一次写

频繁 open/close 文件慢，而且中途崩溃会留下半个文件。

records = []
for epoch in range(1, EPOCHS + 1):
    loss, acc = train_one_epoch()
    records.append({"epoch": epoch, "loss": loss, "acc": acc})

pd.DataFrame(records).to_csv("train_log.csv", index=False)

长时间训练怕丢数据，可以每隔 N 个 epoch 存一次，不要每步都写。

条件筛选

不用写一堆 df["..."]，可读性高得多，而且列名有空格也能用反引号包起来。

大数据量时它比布尔索引略快。

基本用法

    总销量=("销量", "sum"),
    平均价=("价格", "mean"),
    样本数=("销量", "size"),
)

常用聚合函数

写法作用
sum / mean / median求和 / 平均 / 中位数
min / max / std / var最值 / 标准差 / 方差
count / size非空数量 / 总行数
nunique不同值个数
first / last第一个 / 最后一个

transform：结果对齐回原表

# 每个城市的总销量，广播回每一行
df["城市总销量"] = df.groupby("城市")["销量"].transform("sum")

# 每行占本城市总量的比例
df["占比"] = df["销量"] / df.groupby("城市")["销量"].transform("sum")
agg 和 transform 的区别

agg 每个分组返回一行，结果行数变少。

transform 返回和原表一样长的结果，可以直接当新列。
