pandas 用法大全

如果 numpy 解决的是“一堆数字怎么算”，pandas 解决的是“一张带表头和索引的表怎么操作”。 按功能分类速查，用的时候翻。

按功能分类的速查表。基础概念和读取、选取、增删改在入门那课， 这里只放操作细节。所有代码假定已经有 df。

一、缺失值

df.isna()                     # 布尔表
df.isna().sum()               # 每列缺几个
df.dropna()                   # 删掉含缺失的行
df.dropna(subset=["销量"])     # 只看某列
df.fillna(0)                  # 填 0
df.fillna(df.mean(numeric_only=True))   # 填均值
df["c"].ffill()               # 用前一个值填
NaN 不能用 ==

np.nan == np.nan 是 False。判断缺失要用 pd.isna(x)。

筛选非空用 df[df["c"].notna()]，不能写 df["c"] != np.nan。

二、排序与去重

df.sort_values("销量")                 # 升序
df.sort_values("销量", ascending=False)
df.sort_values(["城市", "销量"])       # 多列
df.drop_duplicates()                  # 整行去重
df.drop_duplicates(subset=["城市"])    # 按某列去重
df.reset_index(drop=True)             # 重排行号
df.set_index("城市")                  # 用某列当索引

三、groupby：分组聚合

这是 pandas 最有用的功能。核心是拆开 → 算 → 合起来。

df.groupby("城市")["销量"].sum()
df.groupby("城市")["销量"].agg(["sum", "mean", "count"])
df.groupby(["城市", "年份"])["销量"].sum()      # 多列分组
df.groupby("城市").agg({"销量": "sum", "价格": "mean"})

也可以一次算多个指标并起名：

df.groupby("城市").agg(
    总销量=("销量", "sum"),
    平均价=("价格", "mean"),
)
结果里分组列变成索引了

groupby().sum() 的结果，分组列会变成 index。

想变回普通列，用 .reset_index()。

四、合并

函数作用
pd.concat([a, b])上下堆叠（行拼接）
pd.merge(a, b, on="id")按列关联（SQL 的 join）
a.join(b)按索引关联
pd.merge(订单, 用户, on="用户ID", how="left")
# how: inner(默认) / left / right / outer
merge 之后行数变多

如果右表里同一个 id 有多行，merge 会产生笛卡尔积——行数暴涨。

合并前先检查：b["id"].duplicated().sum()。

五、时间序列

df["日期"] = pd.to_datetime(df["日期"])
df["年"] = df["日期"].dt.year
df["月"] = df["日期"].dt.month
df["星期"] = df["日期"].dt.dayofweek     # 0=周一

df.set_index("日期").resample("M")["销量"].sum()   # 按月汇总

六、字符串

df["城市"].str.contains("京")
df["城市"].str.startswith("北")
df["城市"].str.replace("市", "", regex=False)
df["城市"].str.split("省", expand=True)      # 拆成多列
df["城市"].str.strip()                       # 去首尾空白

七、apply / map

df["c"].map({"男": 1, "女": 0})          # 按字典替换
df["c"].apply(lambda x: x * 2)              # 逐元素
df.apply(lambda row: row["a"] + row["b"], axis=1)   # 逐行
apply 很慢

apply 本质是 Python 循环，比向量化操作慢一到两个数量级。

能用 df["a"] + df["b"] 就别用 apply。能用 .str / .dt 就更好。

八、和 numpy 互通

df.to_numpy()              # 变成 ndarray
df.values                  # 同上（旧写法）
pd.DataFrame(arr, columns=[...])   # ndarray 变表

df["c"].sum()              # pandas 自带聚合，通常够用
np.log(df["c"].to_numpy()) # 复杂运算转 numpy

九、容易踩的坑

坑正确做法
df["a"][0] = 1 报链式赋值警告df.loc[0, "a"] = 1
用 == 判断 NaNpd.isna()
忘了 inplace 或重新赋值大多数方法返回新表，要 df = df.drop(...)
在循环里 df.iterrows() 改数据向量化，或者先收集再一次性赋值
merge 后行数暴涨先检查右表 id 是否唯一
中文列名读进来变成 Unnamed: 0是索引被当成列了，用 index_col=0
整数列里有 NaN 变成 float正常现象：NaN 是浮点数
SettingWithCopyWarning先 .copy() 再改，或直接用 .loc
