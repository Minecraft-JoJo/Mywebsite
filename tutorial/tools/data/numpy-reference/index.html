十三、广播规则

两条数组形状不同时，numpy 按这套规则决定能不能算：

  1. 如果维数不同，在较小的形状前面补 1
  2. 从最后一维开始往前比，每一维必须满足：相等、或其中一个是 1
  3. 不满足就报错；满足的话，长度为 1 的那一维被“复制”到另一边的长度
(3, 4) + (4,)      # → (3,4)，一维被当成 (1,4)
(3, 1) + (1, 4)     # → (3,4)
(5, 3, 1) + (3, 4)  # → (5,3,4)

(3,) + (4,)         # 报错：3 和 4 不相等，也没 1
常见用法：给每行减均值
X = np.random.default_rng(0).random((5, 3))
X - X.mean(axis=0)          # (5,3) - (3,) → 广播，每列减自己的均值
X - X.mean(axis=1)[:, None] # (5,3) - (5,1) → 每行减自己的均值

忘写 [:, None] 会变成 (5,3) - (5,)，报错。

np.append 的陷阱

numpy 数组大小固定，np.append 每次都会新建数组并复制全部旧数据。

循环里用一万次就是 O(n²)。

正确做法：先放进 Python list，最后一次性 np.array(list)。
