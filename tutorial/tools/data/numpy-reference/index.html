numpy 用法大全

按功能分类的速查表。不要求记住，用的时候翻。所有代码都假定已经 import numpy as np。

一、创建数组

从 Python 数据

写法结果
np.array([1,2,3])一维整数数组
np.array([[1,2],[3,4]])2×2 二维数组
np.array([1,2], dtype=float)指定类型
np.asarray(x)已经是数组就不复制

按规则生成

函数作用例子
zeros(shape)全 0np.zeros((2,3))
ones(shape)全 1np.ones(5)
full(shape, v)全 vnp.full(3, 7)
eye(n)单位矩阵np.eye(3)
arange(a,b,step)按步长np.arange(0,10,2) → 0 2 4 6 8
linspace(a,b,n)等分 n 份np.linspace(0,1,5) → 0 .25 .5 .75 1
logspace(a,b,n)等比np.logspace(0,3,4) → 1 10 100 1000
zeros_like(a)同形状全 0也要 ones_like / full_like

随机数

rng = np.random.default_rng(42)     # 固定种子，可复现

rng.random(5)                 # [0,1) 均匀
rng.normal(0, 1, 5)           # 正态，均值 0 标准差 1
rng.integers(0, 10, 5)        # 整数 [0,10)
rng.choice([1,2,3], 5)        # 从给定值里抽
rng.permutation(5)            # 打乱 0..4
rng.shuffle(arr)              # 原地打乱
别再用 np.random.seed()

新的写法是 np.random.default_rng(seed)。旧的 np.random.* 全局状态还能用， 但多个函数互相干扰时会出问题。

属性含义例（a 为 3×4）
a.shape各维长度(3, 4)

a.size元素总数12

类型转换

三、索引与选取

基本索引

a[0]          # 第 0 行（降一维）
a[0, 1]       # 第 0 行第 1 列
a[:, 0]       # 所有行第 0 列
a[1:3]        # 第 1、2 行
a[::2]        # 隔一个取一个
a[::-1]       # 反转

布尔索引

a[a > 5]              # 取出满足条件的元素，返回一维
a[(a > 2) & (a < 8)]    # 与：用 &，不是 and
a[~(a > 5)]             # 非：用 ~
(a > 5).sum()           # 数有多少个满足
这里必须用 & | ~

Python 的 and / or / not 不能作用在数组上，它们只会返回一个标量。

而且 & 的优先级比比较运算符高，一定要加括号：(a > 2) & (a < 8)，不能写 a > 2 & a < 8。

花式索引

a[[0, 2]]           # 取第 0、2 行（结果形状 (2, ...)）
a[[0, 1], [1, 2]]   # 取 (0,1) 和 (1,2) 两个具体位置

按条件取值

np.where(a > 5, 1, 0)      # 满足取 1，否则 0
np.where(a > 5)             # 只给条件 → 返回满足的下标
np.clip(a, 0, 10)           # 截断到 [0, 10]
np.take(a, [0, 2])          # 按索引取
np.select([a<3, a>7], [0, 9], default=5)

四、形状操作

函数作用是否复制
a.reshape(2,6)换读法（元素顺序不变）否，返回视图
a.ravel()拉平成一维否（可能）
a.flatten()拉平成一维是
a.T / a.transpose()转置否
a.swapaxes(0,1)交换两维否
np.expand_dims(a, 0)在某维前加一个长度 1否
np.squeeze(a)去掉所有长度 1 的维否
a = np.arange(12)
a.reshape(3, 4)
a.reshape(2, -1)     # -1 表示"你算"，自动推出 6
a[:, None]           # 把一维变列向量（等价 expand_dims(a, 1)）

五、合并与拆分

函数作用
np.concatenate([a,b], axis=0)沿某维拼接（最通用）
np.vstack([a,b])垂直堆（按行）
np.hstack([a,b])水平堆（按列）
np.stack([a,b], axis=0)堆成新的一维（形状多一维）
np.split(a, 3)等分成 3 份
np.array_split(a, 3)不等分也能切
np.pad(a, 1, constant_values=0)四周补边
np.tile(a, 3)重复平铺
np.repeat(a, 3)每个元素重复 3 次
stack 和 concatenate 的区别

concatenate 是把两条接成一条长的，维数不变。

stack 是把两条摞起来，维数 +1。

两个 (3,)：concatenate → (6,)，stack → (2, 3)。

六、数学运算

逐元素

a + b, a - b, a * b, a / b, a ** 2, a % 3   # 都是逐元素
a // 2                                                  # 整除
np.sqrt(a), np.exp(a), np.log(a), np.sin(a), np.abs(a)  # 通用函数

矩阵乘法

A @ B          # 矩阵乘（推荐）
np.matmul(A, B)
np.dot(A, B)   # 一维时是内积，二维时同 matmul
* 和 @ 完全不同

A * B 是对应位置相乘（要求形状相容）。A @ B 是线性代数里的矩阵乘法。

这是新手最常见的 bug：想算矩阵乘却写了 *，形状恰好对得上，所以不报错，结果全错。

舍入

函数行为
np.round(a, 2)四舍五入到 2 位（银行家舍入）
np.floor(a)向下取整
np.ceil(a)向上取整
np.trunc(a)直接截断小数

七、统计聚合

函数作用
a.sum() / a.mean()求和 / 平均
a.std() / a.var()标准差 / 方差
a.min() / a.max()最小 / 最大
a.argmin() / a.argmax()最小 / 最大所在的下标
a.prod()连乘
a.cumsum() / a.cumprod()累加 / 累乘
np.median(a)中位数
np.percentile(a, 75)分位数
np.quantile(a, [.25,.5,.75])多个分位数
a.any() / a.all()有任意一个真 / 全部为真
a = np.arange(12).reshape(3, 4)

a.sum()         # 66
a.sum(axis=0)   # [12 15 18 21]   每列
a.sum(axis=1)   # [ 6 22 38]      每行
a.cumsum()      # 拉平后累加
a.cumsum(axis=1)# 每行内部累加
axis 的唯一记法

axis=k 表示“把第 k 维压掉”。

(3,4) 沿 axis=0 聚合 → (4,)；沿 axis=1 → (3,)。

别记“行还是列”，那样三维就乱了。

八、比较与逻辑

a > 5                    # 布尔数组
np.array_equal(a, b)      # 完全相等
np.allclose(a, b)         # 浮点近似相等（推荐）
np.isclose(a, b)
np.logical_and(a>1, a<5)  # 等价于 (a>1) & (a<5)

np.count_nonzero(a > 5)   # 数个数
np.unique(a, return_counts=True)   # 去重并计数
浮点数不能用 ==

0.1 + 0.2 == 0.3 是 False。

判断浮点相等用 np.allclose(a, b)，它默认容差 1e-8。

九、排序与查找

函数作用
np.sort(a)返回排好序的新数组
a.sort()原地排序
np.argsort(a)返回排序后的下标
np.argmax(a)最大值的下标
np.searchsorted(a, v)v 该插在哪（要求 a 已排序）
np.nonzero(a)非零元素的下标
np.unique(a)去重并排序
b = np.array([3, 1, 2])
b.argsort()        # [1 2 0]
b[b.argsort()]     # [1 2 3]   ← 用下标做间接排序

# 按某列排序整个表
order = data[:, 1].argsort()
data[order]

十、线性代数

函数作用
A @ B矩阵乘
np.linalg.inv(A)求逆
np.linalg.det(A)行列式
np.linalg.solve(A, b)解 Ax=b（比 inv 快且稳）
np.linalg.eig(A)特征值 / 特征向量
np.linalg.svd(A)奇异值分解
np.linalg.norm(a)范数（默认 L2）
np.trace(A)迹（对角线和）
解方程别用 inv

np.linalg.inv(A) @ b 数学上对，但数值上不稳、还慢。

用 np.linalg.solve(A, b)。

十一、文件读写

二进制（快，专用）

np.save("a.npy", a)          # 存单个数组
np.load("a.npy")               # 读回来
np.savez("ab.npz", a=a, b=b)   # 存多个（不压缩）
np.savez_compressed("ab.npz", a=a, b=b)
d = np.load("ab.npz"); d["a"]

文本（通用，慢）

np.savetxt("a.csv", a, delimiter=",", fmt="%.2f")
np.loadtxt("a.csv", delimiter=",")
np.genfromtxt("a.csv", delimiter=",", skip_header=1)   # 能处理缺失

十二、性能与内存

向量化

# 慢
s = 0
for x in arr:
    s += x

# 快
s = arr.sum()

原地操作

a += 1        # 原地，不新建数组
a = a + 1     # 新建一个数组再赋值
b = a         # 只是多一个名字，同一个数组
b = a.copy()  # 真正复制

视图 vs 拷贝

操作返回
切片 a[1:3]视图
reshape / .T视图
布尔索引 a[a>0]拷贝
花式索引 a[[0,2]]拷贝
astype()拷贝
判断方法

a.base is None → 这是一份独立数据；否则 a.base 是它指向的原数组。

np.shares_memory(a, b) 能直接判断两个数组是否共享内存。

十三、容易踩的坑

坑正确做法
用 and/or/not 做数组逻辑用 & | ~，并加括号
用 == 比较浮点np.allclose
切片改了原数组，以为不相关要独立数据就 .copy()
用 * 当矩阵乘用 @
整数除法 a / b 以为得整数得 float，要整除用 //
把 axis 记成行/列记“哪一维被压掉”
循环里逐个赋值先分配好数组再填，或者向量化
用 np.append 在循环里追加每次都会重新分配内存，先收集到 list 再 np.array
np.append 的陷阱

numpy 数组大小固定。np.append 每次都新建一个数组并把旧数据全复制过去。

在循环里用它追加一万次，复杂度是 O(n²)。

正确做法：数据先放进 Python list，最后一次性 np.array(list)。
