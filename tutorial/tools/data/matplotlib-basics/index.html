matplotlib 入门

它是什么

Python 最基础的绘图库。你看到的绝大多数 Python 图表——论文里的、notebook 里的、 pandas 的 df.plot() 画出来的——底层都是它。

它的定位很低层：告诉它画什么它画什么，不替你做漂亮的默认样式。

为什么先学它，不学 seaborn

seaborn、plotly 这些是在它之上封装的。遇到“想改一个细节”的时候，最终还是要落回 matplotlib。

先把底层学会，上层的一看就懂。

先搞清楚两种写法

同一个图，有两种画法。

写法一：pyplot（像 MATLAB）

import matplotlib.pyplot as plt

plt.plot([1, 2, 3], [1, 4, 9])
plt.title("标题")
plt.show()

不指定对象，靠“当前图”这个概念。适合快速看一眼。

写法二：面向对象（推荐）

fig, ax = plt.subplots()

ax.plot([1, 2, 3], [1, 4, 9])
ax.set_title("标题")
plt.show()
用第二种

一旦有多张图、多个子图，pyplot 写法就会乱——你根本不知道“当前图”是哪一张。

fig 是整张画布，ax 是画布上的一个坐标系。

记住这条：绘制用 ax.plot，设置用 ax.set_xxx。

一张图的骨架

不管画什么，结构都是这五步：

fig, ax = plt.subplots(figsize=(6, 4), dpi=150)   # 1. 建画布

ax.plot(x, y, label="曲线 A")                              # 2. 画

ax.set_xlabel("x")                                         # 3. 标注
ax.set_ylabel("y")
ax.set_title("标题")
ax.legend()

fig.tight_layout()                                         # 4. 收紧边距
fig.savefig("out.png", dpi=200, bbox_inches="tight")       # 5. 保存
figsize 和 dpi 的关系

figsize=(6,4) 单位是英寸，不是像素。

配 dpi=200，实际像素就是 6×200=1200 宽、4×200=800 高。

网页用 150~200 就够，打印要 300。

画第一个图

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 10, 100)     # 0 到 10 均匀取 100 个点

fig, ax = plt.subplots(figsize=(6, 3.5))
ax.plot(x, np.sin(x), label="sin")
ax.plot(x, np.cos(x), label="cos", linestyle="--")
ax.set_xlabel("x")
ax.set_title("两条曲线")
ax.legend()
fig.tight_layout()
plt.show()

关键点：x 要足够密。linspace(0, 10, 100) 取 100 个点，曲线才平滑； 只取 5 个点画出来是折线。

保存

fig.savefig("a.png", dpi=200, bbox_inches="tight")
fig.savefig("a.svg")                    # 矢量图，放大不糊
fig.savefig("a.png", transparent=True)  # 透明背景
savefig 必须在 show 之前

plt.show() 之后画布会被清空。再 savefig，存出来是一张白图。

顺序永远是：画 → tight_layout → savefig → show。

中文显示

默认字体没有中文字形，直接写中文会变成方块。

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei"]
plt.rcParams["axes.unicode_minus"] = False
第二行不能漏

只设字体，负号会变成方块——因为中文字体里的减号不是标准 Unicode 减号。

axes.unicode_minus = False 让它改用 ASCII 的 -。

这两行放在所有绘图代码之前。

一个常见的坑：图叠在一起

如果在循环里反复 plt.plot()，所有线会画到同一张图上。

for i in range(3):
    fig, ax = plt.subplots()      # 每次都新建
    ax.plot(x, data[i])
    fig.savefig(f"fig{i}.png")
    plt.close(fig)                # 用完关掉，释放内存
