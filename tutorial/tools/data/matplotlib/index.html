matplotlib

Python 最基础的绘图库。按功能分类速查。所有代码假定 import matplotlib.pyplot as plt。

一、先搞清楚两种写法

同一个图，有两种画法：

pyplot 接口（简单）

plt.plot([1,2,3], [1,4,9])
plt.title("标题")
plt.show()

像 MATLAB，自动维护"当前图"。适合快速看一眼。

面向对象接口（推荐）

fig, ax = plt.subplots()
ax.plot([1,2,3], [1,4,9])
ax.set_title("标题")
plt.show()
用第二种

pyplot 接口在多图、子图时会乱：你不知道"当前图"到底是哪一张。

fig 是整张画布，ax 是其中一个坐标系。所有绘制都调 ax.xxx， 所有样式都调 ax.set_xxx。

一旦习惯，可读性和可控性都好得多。

二、基本骨架

fig, ax = plt.subplots(figsize=(6, 4), dpi=150)

ax.plot(x, y, label="曲线 A")
ax.set_xlabel("x 轴")
ax.set_ylabel("y 轴")
ax.set_title("标题")
ax.legend()
ax.grid(True, alpha=.3)

fig.tight_layout()
fig.savefig("out.png", dpi=200, bbox_inches="tight")
figsize 和 dpi

figsize=(6,4) 是英寸。配 dpi=200，实际像素就是 1200×800。

网页用 dpi=150~200 就够，打印要 300。

三、常用图

函数画什么
plot(x, y)折线
scatter(x, y)散点
bar(x, h) / barh柱状（竖 / 横）
hist(data, bins=20)直方图
boxplot(data)箱线图
imshow(img)矩阵 / 图片（热力图）
contour / contourf等高线 / 填充等高线
fill_between(x, y1, y2)区间填充
errorbar(x, y, yerr=e)带误差棒的图
pie(sizes)饼图
import numpy as np
x = np.linspace(0, 10, 100)

ax.plot(x, np.sin(x))
ax.scatter(x[::10], np.sin(x[::10]), s=20, c="orange")
ax.hist(np.random.default_rng(0).normal(0, 1, 500), bins=30)
ax.imshow(np.random.default_rng(0).random((10, 10)), cmap="viridis")

四、线和点的样式

简写：一个字符串搞定颜色+线型+标记。

ax.plot(x, y, "ro--")   # 红色圆点 + 虚线
ax.plot(x, y, "b.-")    # 蓝色小点 + 实线

# 等价的长写法
ax.plot(x, y, color="red", linestyle="--", marker="o")
类别可选值
颜色 colorr g b c m y k w 或 "#1f6feb" 或名字 "steelblue"
线型 linestyle- -- -. :（实线/虚线/点划/点线）
标记 markero . s ^ v D x + *
线宽 linewidth数字，默认 1.5
透明度 alpha0~1

五、坐标轴控制

ax.set_xlim(0, 10)          # x 范围
ax.set_ylim(-2, 2)
ax.set_xscale("log")       # 对数轴
ax.set_xticks([0, 5, 10])  # 指定刻度位置
ax.set_xticklabels(["零", "五", "十"], rotation=45)
ax.axhline(0, color="gray", lw=.8)    # 水平参考线
ax.axvline(5, color="gray", lw=.8)    # 垂直参考线
ax.axhspan(-1, 1, alpha=.1)           # 水平区间

六、子图

# 规则网格
fig, axes = plt.subplots(2, 2, figsize=(8, 6))
axes[0, 0].plot(x, y)
axes[0, 1].hist(data)
for ax in axes.flat:          # 遍历所有子图
    ax.grid(True)

# 高度不等
fig, axes = plt.subplots(2, 1, gridspec_kw={"height_ratios": [2, 1]})
共享坐标轴

plt.subplots(2, 1, sharex=True) 让子图共用 x 轴，只显示最下面那个的刻度。

画时间序列的多面板图时很有用。

七、图例

ax.plot(x, y1, label="A")
ax.plot(x, y2, label="B")
ax.legend(loc="upper right", frameon=False, fontsize=9)
ax.legend(bbox_to_anchor=(1.02, 1), loc="upper left")   # 放图外

八、中文显示

默认字体没有中文，会显示成方块。两行搞定：

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei"]
plt.rcParams["axes.unicode_minus"] = False   # 负号也得改
第二行不能漏

第一行改了字体后，负号会变成方块——因为中文字体里的减号不是标准 Unicode 减号。

axes.unicode_minus = False 让 matplotlib 用 ASCII 的 -。

九、保存

fig.savefig("a.png", dpi=200, bbox_inches="tight")
fig.savefig("a.png", transparent=True)   # 透明背景
fig.savefig("a.svg")                     # 矢量图
savefig 必须在 show 之前

plt.show() 之后画布会被清空，再 savefig 存出来是空白图。

顺序：画 → tight_layout → savefig → show。

十一、常见坑

坑解决
中文变方块设 font.sans-serif + axes.unicode_minus=False
存出来是空白savefig 放在 show 之前
子图重叠fig.tight_layout()
图例挡住数据换 loc，或放到图外 bbox_to_anchor
x 轴日期挤成一团fig.autofmt_xdate() 或 rotation=45
在 Jupyter 里不显示开头加 %matplotlib inline
图太小看不清调大 figsize 和 dpi
循环里 plt.plot 画到同一张图每次 subplots() 新建，或者最后 plt.close(fig)

和 pandas 一起用

pandas 的 df.plot() 底层就是 matplotlib，但控制粒度粗。

想要精细控制（双轴、注释、自定义图例），还是取出数据用 ax.plot(df["x"], df["y"]) 自己画。
