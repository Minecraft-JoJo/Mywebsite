一棵树怎么做判断

结构

一棵决策树由三种东西组成：

  • 内部节点：一个问题，比如“湿度 = 高？”
  • 分支：问题的答案，几条分支就有几个答案
  • 叶节点：最终的判断

从根走到叶，就是一连串 if-else。落到哪个叶子，就输出那个叶子的答案。

它其实是在切空间

换一个角度看同一件事：每问一个问题，就是在当前区域里切一刀。

所有问题问完，特征空间被切成了一堆矩形，每个矩形里放一个答案。

轴对齐

每一刀都平行于坐标轴——因为问题永远是“某个特征是否大于某个值”，一次只动一个特征。

这意味着树的决策边界一定是横平竖直的。想用斜线分开？只能用很多小台阶去逼近。

回到上一课的棋盘数据。树能到 0.937，就是因为它可以把空间切成很多小格子，每格一个答案。

叶子不只是答案

如果叶子里的样本不纯，比如有 3 个“是”、1 个“否”，那这个叶子输出的不是一个硬标签，而是比例：

是 0.75，否 0.25。

这就是决策树给出的“概率”。它不是算出来的，是数出来的。

这个“概率”很粗糙

只有 4 个样本，概率只能是 0、0.25、0.5、0.75、1 这几个值。

样本少的叶子里，“0.75”这个数字的不确定性极大。想要更细的概率，得让叶子里的样本更多，但那样树就浅了、拟合能力就弱了。

这是决策树的一个固有矛盾，后面剪枝那课还会遇到。

那问题是怎么选出来的

结构清楚了，剩下最关键的一步：面对一堆可能的特征，先问哪个？

比如“天气”“温度”“湿度”“风”四个特征都能用，从哪个开始？

直觉是：选那个分完之后最整齐的。下一课先把“整齐”这件事量化。
