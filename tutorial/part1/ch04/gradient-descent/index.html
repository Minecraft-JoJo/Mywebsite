逻辑回归的梯度下降

公式已经有了，现在真跑

上一课推出了梯度：

∂w∂J​=m1​i=1∑m​(fi​−yi​)xi​,∂b∂J​=m1​i=1∑m​(fi​−yi​)

其中 fi​=g(wxi​+b)，而 g 就是 Sigmoid。

更新规则和第 2 章一模一样：

w←w−α∂w∂J​,b←b−α∂b∂J​

两个式子重复执行，直到收敛。

这一课不推任何东西，就把这套式子真的转起来，看它到底发生什么。

第 0 步：起点在哪

参数从零开始：w=0，b=0。

这时候 z=0，g(0)=0.5 ——模型对每个样本都说"50% 是良性"，等于什么都没判断。

损失是多少？13 个样本里 7 个恶性、6 个良性：

J=−131​[7log(1−0.5)+6log0.5]=log2=0.6931
记住这个数：0.6931

log2 就是"完全瞎猜"的成本。

二分类问题里，一个什么都不学的模型损失必然停在 0.6931 附近。所以训练开始后，J 只要还贴着这个数，就说明模型还没学到任何东西。

这个数可以当成一把尺子：训练有没有真的起作用，先看 J 有没有掉到 0.6931 以下。

第 1 步：手算一次

先算梯度。fi​=0.5 对所有 i 都成立，所以每个样本的残差都是 0.5−yi​：

前 7 个（y=0）后 6 个（y=1）
残差 f−y+0.5−0.5

于是

∂w∂J​=131​[y=0∑​0.5xi​+y=1∑​(−0.5)xi​]=−0.634615
∂b∂J​=131​[7×0.5+6×(−0.5)]=130.5​=0.038462

取 α=0.5，更新：

w=0−0.5×(−0.634615)=0.3173
b=0−0.5×0.038462=−0.0192

新损失 J=0.680968。

从 0.6931 掉到 0.6810。 掉得不多，但方向对了。

看梯度里藏着的两件事

​∂w∂J​​=0.63，而 ​∂b∂J​​=0.038 ——差了十六倍。

原因还是那个：w 的梯度里多乘了一个 x，而 x 是 1 到 7 之间的数。

所以一开始 w 大步走、b 几乎不动。第 3 章那个"两个参数抢一个 α"的问题，在逻辑回归里一模一样。

实现只有两部分

这个算法实现起来只有两部分：一个循环 + 一个算梯度的函数。

算梯度

def compute_gradient_logistic(X, y, w, b):
    m, n = X.shape
    dj_dw = np.zeros(n)
    dj_db = 0.0
    for i in range(m):
        f = sigmoid(X[i] @ w + b)      # 这一条的预测
        err = f - y[i]                 # 残差
        for j in range(n):
            dj_dw[j] += err * X[i, j]  # 残差乘特征
        dj_db += err
    return dj_dw / m, dj_db / m

循环

def gradient_descent(X, y, w, b, alpha, num_iters):
    for i in range(num_iters):
        dj_dw, dj_db = compute_gradient_logistic(X, y, w, b)
        w = w - alpha * dj_dw
        b = b - alpha * dj_db
    return w, b
两次更新必须用同一份梯度

注意顺序：先算完 ∂w∂J​ 和 ∂b∂J​，再一起更新。

如果先更新了 w，然后拿新的 w 去算 ∂b∂J​，那算出来的就不是同一个点的梯度了——这叫非同步更新，会让收敛变慢甚至出错。

代码里 dj_dw, dj_db = compute_gradient(...) 这一行同时拿到两个梯度，就是为了保证这一点。

和第 2 章比一比

把两个算法摆在一起看，会发现它们的骨架完全一样：

线性回归逻辑回归
预测f=wx+bf=g(wx+b)
损失2m1​∑(f−y)2−m1​∑[ylogf+(1−y)log(1−f)]
梯度m1​∑(f−y)xm1​∑(f−y)x
更新w←w−α∂w∂J​同左
循环重复直到收敛同左

只有前两行变了。 梯度的形式、更新规则、循环结构，一个字都没改。

这就是为什么逻辑回归学起来不费劲——它只是在线性回归外面套了一层 g，再把损失换成配得上分类的那一个。

一个诚实的补充

这 13 个样本是线性可分的：所有恶性都在 3.5 cm 以下，所有良性都在 4.0 cm 以上。

这种数据上，逻辑回归的最优解在无穷远处——w 越大、b 越负，分得越干净，损失越接近 0 但永远到不了 0。

所以上表里 J 到第 2000 步还在缓慢下降，不是没收敛好，是本来就没有一个有限的终点。真实数据很少这么干净，通常会有重叠，那时 J 会收敛到一个正数。
