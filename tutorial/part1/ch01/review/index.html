回顾

第 1 章做了什么

三件事，一件比一件具体。

先说了这条路走不通。 用 if 写规则，规则永远补不完——对方一变，你就得加一条。还有一些任务连规则都写不出来：你怎么用 if 描述"这是一只猫"？

然后换了个方向。 不给规则，给例子。给机器十万封标注好的邮件，它自己找出一套判断规则。这件事说到底只有一句：从数据里找出一个函数。

最后把问题分了类。 按训练时有没有标准答案，分成监督、无监督、强化学习。监督学习内部再按标签类型分成回归和分类。

三个容易搞混的地方

一、监督和无监督，区别在于有没有标签，不在于任务叫什么名字。

"给用户分群"听起来像有目标，但如果你没有告诉模型"哪几个人应该是一组"，它就是无监督。 "垃圾邮件识别"听起来像个判断任务，但每封邮件都标了"是 / 否"，它就是监督。

二、回归和分类，区别在于标签是什么，不在于预测什么东西。

"明天会不会下雨"是分类（标签是 会 / 不会）。 "明天下多少毫米"是回归（标签是数字）。

同一个问题两种定法都成立，取决于你把标签定义成什么。

三、特征和参数，一个是给的，一个是学的。

特征是你从数据里读出来的（面积、房龄）。 参数是模型自己调出来的（w、b）。

训练的过程，就是固定住特征、不断调整参数。

自测

合上这一章，能答上来就说明学明白了：

  1. 为什么"用 if 写规则"在垃圾邮件上会失败？举一个具体的对抗例子。
  2. "从数据里找出一个函数"——这句话里的"函数"，输入和输出分别是什么？
  3. 一份用户购买记录，没有标签。你能用它做什么？不能做什么？
  4. 房价预测是回归还是分类？如果改成"这套房会不会在三个月内卖掉"呢？
  5. 模型里的 w 和 b，是数据给的还是学出来的？
