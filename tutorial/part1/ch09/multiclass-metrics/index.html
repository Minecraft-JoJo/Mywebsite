多分类怎么评估

三个类，一个矩阵

多分类也能画混淆矩阵，只是从 2×2 变成 K×K：

预测 A预测 B预测 C该行合计
实际 A5010565
实际 B840250
实际 C1263048
该列合计705637163

对角线上的 50、40、30 是判对的，其余是判错的。

总准确率 = (50+40+30)/163=120/163=0.736。

但如果你想知道"每个类别各自好不好"，就得按类拆开算。

先按类算

对每一类，把它当成"是这一类 vs 不是这一类"的二分类：

类别精确率召回率
A50/70=0.71450/65=0.769
B40/56=0.71440/50=0.800
C30/37=0.81130/48=0.625

看出来了：C 的精确率高（报出来的多半是对的），但召回率最低（48 个里漏了 18 个）。

只报总准确率 0.736 的话，这个信息完全看不到。

三个数怎么合成一个

问题来了：三个类别的召回率是 0.769 / 0.800 / 0.625，怎么合成一个数？

有三种平均方式，它们给出的答案不一样。

macro（宏平均）

直接把三个数平均，不管每类有多少样本：

macro=30.769+0.800+0.625​=0.731

每个类别权重相同，哪怕 C 只有 48 个样本、A 有 65 个。

weighted（加权平均）

按每类的样本数加权：

weighted=1630.769×65+0.800×50+0.625×48​=0.736

样本多的类别话语权大。

micro（微平均）

把所有类别混在一起算：

micro=16350+40+30​=0.736
什么时候三者相等，什么时候不相等

对召回率：micro 和 weighted 总是相等。因为两者最后都是"总判对数 / 总样本数"。

对精确率：三者一般都不相等。

macro 和另外两个的区别最大——它给小类别和 D 类同样的权重。

该用哪个

场景选择理由
各类样本量差不多无所谓三者接近
类别不平衡，且每个类都重要macro小类不会被大类的成绩淹没
类别不平衡，但更关心总体表现weighted反映真实的业务分布
只想要一个"整体正确率"micro就是准确率
一个容易被坑的地方

假设 990 个样本是 A 类，10 个是 B 类。模型全判 A：

  • 准确率（micro）= 0.99
  • macro 召回率 = (1.0+0)/2=0.5

同一个模型，两个数字差一倍。

所以报多分类指标时，一定要写清楚用的是哪种平均。只写"召回率 0.99"是不负责任的。

本章小结

概念内容
准确率的陷阱类别不平衡时，全判多数类就能拿高分
混淆矩阵TP / FP / FN / TN，四种结果代价不同
精确率TP/(TP+FP)，报出来的有几个是真的
召回率TP/(TP+FN)，真的抓到了几个
F1调和平均，惩罚极端值
阈值决策不是模型，由业务代价定
ROC / AUC衡量排序能力，与阈值和类别比例无关
AUC 的含义随机取一正一负，正样本得分更高的概率
macro / weighted / micro三种平均方式，结论可能差很多
