正则化逻辑回归

加法完全一样

逻辑回归的损失是交叉熵，加正则化的方式和上一课一个字都不用改：

J(w,b)=−m1​i=1∑m​[yi​logfi​+(1−yi​)log(1−fi​)]+2mλ​j=1∑n​wj2​

还是那个套路：原损失 + 参数的平方和，b 不参与。

梯度也一样

∂wj​∂J​=m1​i=1∑m​(fi​−yi​)xij​+mλ​wj​
∂b∂J​=m1​i=1∑m​(fi​−yi​)
和线性回归的梯度对比

上一课写的是：

∂wj​∂J​=m1​∑(f−y)xij​+mλ​wj​

这一课写的还是这个。

唯一的区别藏在 f 里：线性回归的 f=wx+b，逻辑回归的 f=g(wx+b)。公式的外形、正则化项、b 的处理，全部相同。

实现上怎么加

如果你已经写了逻辑回归的梯度函数，加正则化只需要改两行：

def compute_gradient(X, y, w, b, lam):
    m, n = X.shape
    f = sigmoid(X @ w + b)
    err = f - y
    dj_dw = (X.T @ err) / m + (lam / m) * w    # ← 这里加了后半截
    dj_db = np.mean(err)                       # ← b 不动
    return dj_dw, dj_db

注意 dj_dw 那行：拟合的梯度算完之后，再加上 (lam/m)*w。

为什么可以这样随便加

因为它只依赖一件事：损失函数里多了 2mλ​∑wj2​ 这一项。

这一项对 wj​ 求导永远等于 mλ​wj​，不管前面的损失是什么。

所以：

模型原损失加正则化后
线性回归平方误差+2mλ​∑wj2​
逻辑回归交叉熵+2mλ​∑wj2​
神经网络任意+2mλ​∑wj2​

正则化是加在损失外面的一层，和具体用什么损失无关。

一个实际效果

逻辑回归在多特征的时候同样会过拟合。

比如判断肿瘤时用了 20 个特征，其中大部分是噪声——模型会把它们的权重调得很大，恰好穿过训练集的每个点。

加正则化之后，那些噪声特征的权重被压到接近 0，模型只依赖真正有用的那几个。

这和第 6 章的特征选择是同一个目的

第 6 章说"扔掉没用的特征"能治过拟合。

正则化是它的软版本：不扔掉，但把权重压小。压得足够小的话，效果和扔掉差不多——这也是为什么第 5 课的 L1 能做到"正好压成 0"。

下一课

L2 只是把权重压小。L1 更狠：它会把一些权重压到正好等于 0。

这个差别背后有个很漂亮的几何解释。
