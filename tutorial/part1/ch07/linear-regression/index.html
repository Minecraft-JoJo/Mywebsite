正则化线性回归

梯度怎么变

加上正则化项之后，重新求导。

先说结论：原来那部分梯度一个字没变，只是在后面接了一项。

这件事值得停一下。损失函数明明多了一整项，为什么梯度只是"多接一项"？

因为加上去的那一项只含 w，不含拟合项里的任何东西。求导时互不干扰，各算各的。

具体：

∂wj​∂J​=m1​i=1∑m​(f(xi​)−yi​)xij​+mλ​wj​
∂b∂J​=m1​i=1∑m​(f(xi​)−yi​)

注意 b 的梯度完全没变——因为它不在正则化项里。

更新式长出一个新样子

把梯度代进更新式：

wj​←wj​−α[m1​∑(f−y)xij​+mλ​wj​]

把 wj​ 的项提到一起：

wj​←wj​(1−αmλ​)−αm1​∑(f−y)xij​
看那个括号

wj​(1−αmλ​) —— 每一项更新之前，先把自己乘上一个略小于 1 的系数。

也就是说：每一步都先把 wj​ 往 0 缩一点点，然后再按普通梯度走一步。

缩多少？αλ/m。λ 越大，缩得越狠。

这就是正则化在梯度下降里的真实样子：每步衰减一点。

名字的由来

因为这个"每步先缩一点"的动作，L2 正则化在深度学习里常被叫作 权重衰减（weight decay）。

同样的东西，两个名字：

名字从哪个角度看
L2 正则化从损失函数看：加了一项惩罚
权重衰减从更新式看：每步乘一个衰减因子

是同一件事。

正规方程也要改

第 3 章那个直接求解的公式：

θ=(X⊤X)−1X⊤y

加上正则化后变成：

θ=(X⊤X+λR)−1X⊤y

其中 R 是一个对角矩阵，最后一个对角元是 0（对应 b），其余是 1：

R=​1​1​⋱​0​​
那个 0 就是"不罚 b"

如果所有对角元都设成 1，b 也会被惩罚。所以必须把对应 b 的那一格改成 0。

这就是"只罚 w"这句话在矩阵里的样子。

看训练误差那一列：从 2.346 到 2.840，变化很小——正则化并没有让模型在训练集上变差多少。

正则化的收益和代价完全不对等：花掉一点点训练精度，换来大幅的泛化提升。

拓展：为什么加 λR 能让矩阵一定可逆

（这一段可以跳过，不影响后面。）

第 3 章提过一句：X⊤X 可能不可逆，这时候正规方程无解。加了正则化之后，这个问题消失了。

原因是矩阵的特征值。X⊤X 是半正定的，特征值 μi​≥0。某些特征值可能是 0——那就不可逆。

加上 λR 之后，特征值变成 μi​+λ：

  • 原来的 0 变成了 λ>0
  • 所有特征值都严格大于 0

一个特征值全为正的对称矩阵一定可逆。

所以正则化顺手解决了不可逆的问题。这在特征数比样本数还多的时候（n>m，此时 X⊤X 必然不满秩）特别有用。
