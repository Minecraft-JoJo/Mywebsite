L1 和 L2

两种惩罚

前面用的都是平方。

你在别处会看到另一个名字——lasso，它用的不是平方，是绝对值。

两个都能治过拟合，为什么并存？

因为它们的后果很不一样。这一课讲清楚这个差别——它决定了你该选哪个。

先看平方

j∑​wj2​

这叫 L2 正则化，也叫岭回归（ridge regression）、权重衰减。

换成绝对值：

j∑​∣wj​∣

这叫 L1 正则化，也叫 lasso。

L1 的"压成 0"是精确的 0

不是"很小很小"，是真的等于 0。

如果你有 100 个特征，L1 可能让其中 80 个的权重变成 0——模型实际上只用了 20 个特征。

这叫稀疏解（sparse solution）。

为什么 L1 会产生 0

这件事有个很直观的几何解释。

把问题换个说法：最小化损失的同时，要求 ∑∣wj​∣≤t 或 ∑wj2​≤t。这两个约束的"形状"不同：

  • L2 的约束是个圆（高维时是球）。等高线从外面缩进来，第一次碰到圆的地方，一般在一个光滑的弧上——坐标不会是 0。
  • L1 的约束是个菱形（高维时是多面体）。它有尖角，而且尖角正好落在坐标轴上。等高线缩进来时，很容易先碰到尖角——那一点的意思是：某个权重等于 0。
二维时是菱形，高维时是"带尖角的超多面体"

维度越高，尖角越多，L1 把权重压成 0 的倾向越明显。

这就是为什么 L1 天然适合做特征选择。

相关特征为什么对 L1 不友好

假设两个特征几乎一样。L1 的惩罚是 ∣w1​∣+∣w2​∣——在 w1​+w2​=c 这条线上，这个和是常数。

也就是说：L1 不在乎这两个权重怎么分配，它会在 w1​=c,w2​=0 和 w1​=0,w2​=c 之间随便挑一个。

换一批数据，挑的可能就变了。这就是"不稳定"。

L1 确实把系数压到了 0（6 → 4 → 2 → 1），但验证误差反而更差。

原因：这 6 个多项式项每一个都有用，压掉哪个都损失信息。

L1 的优势在于"特征里混了大量废物"的时候。这组数据没有废物，所以它只是白扔了有用的东西。

稀疏不等于更好。 只有当被扔掉的东西真没用时，L1 才占优。

L1 的 λ 量级和 L2 不一样

因为绝对值函数的导数是常数（±1），而平方的导数是 2w（随 w 变小而变小）。

结果是：L1 在小权重上推得更狠，所以用同一个 λ 值，L1 的效果通常比 L2 强得多。

实际调参时两者要分开扫。

拓展：为什么"绝对值"的导数是常数

（可以跳过。）

对 ∣w∣ 求导：

dwd​∣w∣={+1−1​w>0w<0​

它不看 w 有多大——不管 w=5 还是 w=0.001，推力都是 1。

而平方的导数是 2w：w 越接近 0，推力越小。

这就是差别的根源
  • L2：w 越小，推力越弱 → 无限接近 0，但停不下来
  • L1：推力恒定 → 一直推到 0，然后被"卡住"（0 点不可导，梯度下降会停在附近并保持）

所以 L1 能把权重真正推到 0，而 L2 只能让它无限接近 0。
