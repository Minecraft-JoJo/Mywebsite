注意那个"过冲"

第 0 步的 w=1.0 离最优很远，所以第一次更新的步子最大（w 一下跳到 2.24）。

这正是梯度下降的设计：离得越远走得越猛，越靠近越谨慎。 你不需要告诉它"还有多远"。

完整代码

import numpy as np

area  = np.array([55, 62, 70, 78, 85, 92, 100, 108, 115, 125, 135, 145], float)
price = np.array([212.5, 241.2, 261.2, 280.5, 311.1, 328.1,
                  370.8, 416.8, 415.6, 448.8, 499.4, 532.5])
m = len(area)

w, b = 1.0, 0.0        # 初始参数
alpha = 4.5e-5         # 学习率

for step in range(21):
    y_hat = w * area + b       # 前向：算预测
    err   = y_hat - price      # 残差
    loss  = np.mean(err ** 2) / 2

    dw = np.mean(err * area)   # 对 w 的偏导
    db = np.mean(err)          # 对 b 的偏导

    print(f"{step:3d}  w={w:.4f}  b={b:.4f}  J={loss:.2f}")

    w = w - alpha * dw         # 同时更新
    b = b - alpha * db

二十几行，没有库调用，没有黑盒。这就是全部。

这是哪种梯度下降

你算梯度的时候，用的是全部 12 个样本：

∂w∂J​=m1​i=1∑m​(y^​(i)−y(i))x(i)

那个 m1​∑ 就是"把所有样本的梯度加起来，再除以样本数"。每次更新只用了一个数——全体样本的平均梯度。

这叫批量梯度下降（batch gradient descent）。

名称每步用几个样本梯度怎么算特点
批量 batch全部 m 个m1​∑方向最准，但数据大时每步极慢
随机 SGD1 个单个样本的梯度快但抖，方向只代表一个样本
小批量 mini-batchk 个（如 32、256）k1​∑折中，实际训练默认用法
小批量只是把 $m$ 换成 $k$

公式长得一模一样，唯一区别是求和范围：

∂w∂J​=k1​j∈本批∑​(y^​(j)−y(j))x(j)

本书前面用的全是批量版本——数据只有 12 个点，一次算完没关系。等到了深度学习，一条样本是几万维的张量，才必须分批。

但最后没到底

看那张损失曲线：第 20 步停在 42.1，而绿点标的真实最低是 37.27，在它下面。

差在哪？看参数：

第 20 步的值真实最优
w3.6823.575
b0.02611.344

w 已经到位了，b 还差得远——从 0 爬到 11.3，它爬了 20 步才到 0.026。

前两课已经说过原因：∂J/∂w 乘了面积（量级约 100），∂J/∂b 只是残差本身（量级约 1）。同一个 α，两边的速度差了一百倍。

结果就是：直线看起来已经贴合了（因为斜率对了），但整体位置还差一截——它比正确的位置略微靠下。

这不是终点，是下一章的入口

想靠调大 α 解决？不行——α 再大一点，w 那边直接爆炸（上一课红色那条）。

唯一的正解是先把特征缩放到同一量级，让两个方向的梯度自然同尺度。那时同样的 α 会同时对 w 和 b 好用。

这正是下一章要做的第一件事。

核心概念（全章）

概念一句话
线性回归用 f(x)=wx+b 拟合数据
参数w（斜率）和 b（截距），是学出来的
超参数学习率 α、迭代轮数，是你手动定的
损失函数 J输入一组参数，输出一个数，越小越好
均方误差2m1​∑(y^​−y)2，回归的标准损失
残差y^​−y，竖直方向的差，不是点到直线的垂距
导数 / 偏导该参数挪一点，损失变多少；符号给方向，大小给陡峭度
梯度所有偏导组成的向量，指向最陡上坡方向
梯度下降沿负梯度方向反复迈小步
更新式θ←θ−α∇J
同时更新两个偏导都用旧参数算，算完再一起赋值
学习率步长；太大震荡爆炸，太小慢到没用
步长自适应越接近谷底梯度越小，步子自然变小
批量梯度下降每步用全部样本算平均梯度
小批量把 m 换成批大小 k，其余不变
局部最优只能保证脚下是平的，不保证是全局最低
病态 / 量纲各参数梯度量级差异大，导致收敛速度悬殊
