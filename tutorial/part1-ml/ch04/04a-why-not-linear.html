线性回归为什么做不了分类

一个具体的目标

给出一张肿瘤的检查数据，判断它是良性还是恶性。

先把问题简化到最小：只有一个特征——肿瘤大小（cm），标签只有两种：

标签 含义
y = 1 良性
y = 0 恶性

现有 13 个已确诊的样本：

注意这张图最关键的一点：所有点只可能在两条线上（y=0 或 y=1）。中间那片区域是空的——一个肿瘤不可能”70% 良性”。

先用老办法试试

第 2 章那套是现成的：找一个 f(x) = wx + b，用最小二乘拟合这些点。

拟合出来的直线就是左图那条绿色的线。它大致是这个方向：

  • 肿瘤小的地方，预测值接近 0（恶性）
  • 肿瘤大的地方，预测值接近 1（良性）

看起来挺合理。但有两个问题。

问题一：它会给出荒谬的预测

线性回归的输出没有任何边界。左图里，当肿瘤大小到 7-8 厘米时，直线的预测值已经超过 1 了；往左推，预测值会变成负数。

可是”良性程度 1.3”是什么意思？“−0.2 的良性概率”又是什么？

概率只能落在 [0, 1]。线性回归不知道这件事，它只负责让平方误差最小。

注记一个自然的补救想法

“那就取个阈值呗——预测值大于 0.5 判为良性，小于 0.5 判为恶性。”

这个想法是对的，而且逻辑回归最后也会这么做。

但它救不了线性回归，因为下面这个问题。

问题二：几个新样本就能毁掉整条边界

假设医院又送来 3 个样本，都是很大的肿瘤（12、14、16 厘米），而且都是良性。

数据只多了 3 个点。重新拟合：

对比两条绿线：

原始数据 加 3 个点后
斜率 w 0.2353 0.0766（降了 67%）
截距 b −0.4163 0.1293
0.5 阈值处的边界 x = 3.89 cm x = \mathbf{4.84} cm

判定的分界线整个右移了差不多 1 厘米。

这意味着什么？原来一个 4.2 厘米的肿瘤会被判为良性（因为 4.2 > 3.89）；现在同样的 4.2 厘米，因为 4.2 < 4.84，会被判为恶性。

警告这就是问题所在

那 3 个新样本和这个 4.2 厘米的肿瘤毫无关系——它们在图的另一端，离得很远。

已经确诊的样本，凭什么因为别人的数据被改变诊断？

这在直觉上就说不通。而现实中样本会一直增加，模型的判断跟着漂来漂去，这是不可接受的。

为什么会这样

根源在于线性回归用的损失函数：

J = \frac{1}{2m}\sum\left(\hat{y} - y\right)^2

平方误差对”离得远”的预测惩罚极重。

那 3 个 12-16 厘米的样本，如果保持原来的斜率，预测值会是 2.4、2.9、3.4——残差有 1.4 到 2.4 那么大，平方之后就是 2 到 6。

而剩下 13 个点的残差都在 0 到 1 之间，平方后不到 1。

几个远端的点，靠平方误差就能把整条线拽过去。 线性回归为了迁就它们，只能把斜率压小、整条线压平。

这不是参数没调好，是模型本身的性格。

注记更根本的一点：平方误差在分类问题上本身就问错了问题

分类只关心一件事：预测值在 0.5 的哪一边。

假设 y = 1，模型预测 0.9 和预测 3.7，在分类意义上完全等价——都判对了。

但平方误差认为预测 3.7 更差（(3.7-1)^2 = 7.29 对 (0.9-1)^2 = 0.01），会拼命把它拉回来。这个”努力”不仅没用，还会破坏已经学好的边界。

损失函数和任务目标不一致，这是更深的病根。

所以我们想要什么

从上面两个问题反推，分类模型的输出应该满足：

需求 为什么
输出限制在 (0, 1) 才能当概率解释
不能超出这个范围 否则”1.3 的良性概率”没有意义
对远离边界的样本不敏感 一个 16 厘米的良性肿瘤不该翻动边界
输出是平滑的 S 形 从”确定恶性”平滑过渡到”确定良性”

前三条 f = wx + b 一条都给不了。

第四条指的是形状：我们希望预测值随着肿瘤变大，从 0 慢慢爬升到 1，而不是像直线那样冲过头再冲回来。中间在某个点附近快速切换——那条分界线才是真正该待的地方。

提示这种形状叫 Sigmoid

它的图像是一条 S 形曲线：两头无限逼近 0 和 1，中间陡峭。

不管输入多大或多小，输出永远落在 (0, 1) 里面——永远不会超出范围。

而且它对远处的点天然不敏感：输入从 12 变成 16，输出可能只是从 0.99 变成 0.999，几乎不动。那 3 个远端样本再也拽不动边界了。

逻辑回归

把上面这些需求装进一个算法，就是逻辑回归（logistic regression）。

重要别看名字里有”回归”

它是分类算法，不是回归。

名字是历史遗留问题——因为它内部确实还算了 wx + b，只是外面套了一层把结果压到 (0,1) 的函数。

它的工作方式大概是：

  1. 内部照旧算 z = wx + b，这一步和线性回归一模一样
  2. 用 Sigmoid 把 z 压到 (0, 1)：z 很大时输出接近 1，很小时接近 0
  3. 输出的这个数，解释为”属于良性类的概率”
  4. 拿 0.5 当阈值，得到最终判断：\hat{y} = 1 或 0

所以它给你的不是一个生硬的 0/1，而是一个有把握程度的概率——“这个肿瘤有 87% 的概率是良性”，比单纯的”良性”信息量大得多。

线性回归 逻辑回归
输出范围 (-\infty, +\infty) (0, 1)
输出含义 一个数 概率
典型损失 平方误差 交叉熵
是否受远端样本影响 影响很大 影响很小
用途 回归 分类
