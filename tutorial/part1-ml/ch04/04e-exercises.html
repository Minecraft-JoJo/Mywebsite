习题

用到的公式

模型、损失、梯度、更新，四件套：

f_i = g(w^{\top}x_i + b) = \frac{1}{1+e^{-(w^{\top}x_i+b)}}

J(w,b) = -\frac{1}{m}\sum_{i=1}^{m}\left[\,y_i\log f_i + (1-y_i)\log(1-f_i)\,\right]

\frac{\partial J}{\partial w_j} = \frac{1}{m}\sum_{i=1}^{m}\bigl(f_i-y_i\bigr)x_{ij}, \qquad \frac{\partial J}{\partial b} = \frac{1}{m}\sum_{i=1}^{m}\bigl(f_i-y_i\bigr)

w_j \leftarrow w_j - \alpha\frac{\partial J}{\partial w_j}, \qquad b \leftarrow b - \alpha\frac{\partial J}{\partial b}

（提示：数一下有几个 y=1、几个 y=0。）

第三组 · 拓展

第八题　写出这个两特征模型的决策边界方程。它在 (x_1, x_2) 平面上是什么形状？

第九题　如果你坚持不标准化，\alpha 最大能取到多少还能收敛？和 0.05 差几倍？为什么差这么多？

提示建议

第一组手算完全可行——十三个样本，每个样本只有一次乘法和一次对数。

第二组必须写代码。不要手算，二十个点加上迭代，手算没有意义。

答案

注记第一题

预测全是 0.5，所以每个样本的损失是 -\log 0.5 = \log 2，不管它是 0 还是 1。

J(0,0) = \log 2 = \mathbf{0.6931}

这就是”完全瞎猜”的成本。二分类问题里，任何什么都不学的模型，损失都停在这个数附近。

注记第二题

f_i = 0.5 对所有 i 成立，残差 f_i - y_i 只有两种取值：

  • 前 7 个（y=0）：+0.5
  • 后 6 个（y=1）：-0.5

\frac{\partial J}{\partial b} = \frac{1}{13}\left[7\times 0.5 + 6\times(-0.5)\right] = \frac{0.5}{13} = \mathbf{0.038462}

\frac{\partial J}{\partial w} = \frac{1}{13}\left[\sum_{y=0}0.5x_i - \sum_{y=1}0.5x_i\right] = \mathbf{-0.634615}

差了 16.5 倍。原因：w 的梯度里多乘了一个 x，而 x 的均值是 3.73。

注意两个梯度的方向是反的：\partial J/\partial w 是负的（w 该增大），\partial J/\partial b 是正的（b 该减小）。

注记第三题

w = 0 - 0.5\times(-0.634615) = \mathbf{0.3173} b = 0 - 0.5\times 0.038462 = \mathbf{-0.0192}

新损失：

J = \mathbf{0.680968}

只降了 0.012。因为梯度本身不大，而 \alpha 只有 0.5。

注记第四题

第 10 步：w = 0.2934，b = -0.7537，J = \mathbf{0.526005}。

对比：

步数 J 这一段降了多少
0 0.69315 —
1 0.68097 0.012
10 0.52600 0.155

前十步降得比第一步快得多——因为第一步之后 b 开始动起来，预测不再全是 0.5，梯度本身也在变大。

如果继续跑到第 2000 步，J 会到 0.0617。

注记第五题

起点预测全是 0.5，所以残差还是 \pm 0.5：

\frac{\partial J}{\partial b} = \frac{1}{20}\left[8\times 0.5 + 12\times(-0.5)\right] = \mathbf{0.1000}

\frac{\partial J}{\partial w_1} = \mathbf{-0.5100}, \qquad \frac{\partial J}{\partial w_2} = \mathbf{4.4175}

两个 w 的梯度差了近 9 倍，符号还相反。

原因很直接：w_2 对应的是年龄，数值在 30 到 70 之间；w_1 对应的是肿瘤大小，只有 1 到 8。梯度里乘的特征越大，结果就越大。

这意味着同一个 \alpha 对 w_2 太激进、对 w_1 太保守。

注记第六题
步数 不缩放 标准化后
0 0.69315 0.69315
1 4.92110 0.68388
5 11.05241 0.64926
20 0.50877 0.54827
100 11.05241 0.34162
200 11.05241 0.27558

不缩放那一列是发散的：第一步损失就冲到 4.92（比起点高七倍），第 5 步到 11.05，之后就在 11.05 和 0.51 之间来回震荡，再也没下来过。

第 20 步那个 0.5088 是个陷阱——它只是震荡路过的一个低点，不是收敛。

标准化之后一切正常：单调下降，200 步到 0.2756。

同一个算法、同一个学习率，只因为做了缩放，一个彻底失败、一个顺利收敛。

注记第七题

标准化后训练出来的参数：

w = [1.758,\ 0.270], \qquad b = -0.446

用它们预测 20 个样本，准确率 = 18 / 20 = 90%。

错的两例是图中重叠区域的那两个点——一个是蓝色圆点混在橙方块里，一个是反过来。

注记第八题

决策边界是 z = 0 的解集：

w_1x_1 + w_2x_2 + b = 0

这是 (x_1, x_2) 平面上的一条直线。

因为 g 单调递增且 g(0)=0.5，所以”预测大于 0.5”等价于”z>0“——边界完全由 z 的正负决定，g 不参与。

要让边界变成曲线，得像第 3 章那样加多项式特征（x_1^2、x_1x_2 等）。

注记第九题

用 2000 步试几个 \alpha：

\alpha 最终 J
0.05 1.381（失败）
0.02 0.630
0.01 0.312
0.005 0.275（和不缩放的最好结果持平）
0.002 0.296

能用的上限大约在 0.005，比 0.05 小了十倍。

原因：稳定性要求 \alpha < \dfrac{2}{\lambda_{\max}}，而 \lambda_{\max} 大致按特征尺度的平方增长。年龄的尺度是大小的大约 9 倍，平方之后就是 80 倍——所以 \alpha 必须缩得比 9 倍还狠。

这正是第 3 章那个条件数问题的翻版。

一句话总结

现象 原因
起点损失恒等于 \log 2 预测全 0.5，每个样本都罚 \log 2
两个 w 的梯度量级不同 梯度里乘了特征本身，特征尺度不同
不缩放会发散 \alpha 被最大的那个特征尺度卡住
g 不影响决策边界 边界是 z=0，与 g 无关
