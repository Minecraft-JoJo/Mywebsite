手算自注意力

前两课讲清了概念。这一课把每一步都算出来。

算完之后，QK⊤、softmax、加权求和这三件事就有了具体印象。

设定：压到最小

量值为什么这么小
token 数3多了手算不动
d_model4每个 token 4 维
d_k2Q、K、V 各 2 维

3 个 token，每个 4 维的输入矩阵：

X=​101​011​100​010​​

三个权重矩阵（4 行 2 列，把 4 维压成 2 维）：

Wq​=​1010​0101​​,Wk​=​0101​1010​​,Wv​=​1010​0110​​
三个矩阵在干什么

同一份 X 经过三个不同矩阵，得到三份不同的表示。

真实模型里这三个是训练出来的；这里是我手选的，为了让结果好算。

第 1 步：算 Q、K、V

Q=XWq​=​201​021​​,K=XWk​=​021​201​​,V=XWv​=​201​111​​

手验 Q 的第 1 行：

X 第1行   = [1, 0, 1, 0]
W_q 第1列 = [1, 0, 1, 0]   点积 = 1+0+1+0 = 2
W_q 第2列 = [0, 1, 0, 1]   点积 = 0+0+0+0 = 0

所以 Q 第1行 = [2, 0]
Q 和 K 不一样，这不奇怪

都由 X 变来，但用了不同矩阵。

这正是 36.2 说的：不能用 X 自己当 Q 和 K， 否则「每个词和自己比」永远是最大值。

第 2 步：算分数矩阵

QK⊤=​042​402​222​​
位置计算结果
(1,1)[2,0] · [0,2]0
(1,2)[2,0] · [2,0]4
(1,3)[2,0] · [1,1]2
(3,1)[1,1] · [0,2]2
看 (1,1) 这一格

token 1 和自己的分数是 0，和 token 2 是 4。

token 1 觉得 token 2 比自己更重要。

这正说明自注意力不是简单复制自己。

这个矩阵看上去对称，但那是巧合。 一般情况下 QK⊤ 不是对称的——qi​⋅kj​ 和 qj​⋅ki​ 没有关系。

第 3 步：除以 dk​​

这里 dk​=2，除以 2​≈1.4142：

2​QK⊤​=​02.82841.4142​2.828401.4142​1.41421.41421.4142​​

就是把每个数缩小 1.41 倍。为什么这么做，下一课专门讲。

第 4 步：softmax（按行）

A=softmax(2​QK⊤​)=​0.04540.76790.3333​0.76790.04540.3333​0.18670.18670.3333​​

逐行手算第 1 行：

第1行 = [0, 2.8284, 1.4142]

取指数：
  e^0      = 1.0000
  e^2.8284 = 16.9168
  e^1.4142 =  4.1133
  合计     = 22.0301

归一化：
  1.0000 / 22.0301 = 0.0454
  16.9168 / 22.0301 = 0.7679
  4.1133 / 22.0301 = 0.1867

三者相加 = 1.0000
为什么是「按行」不是「按列」

第 1 行是 token 1 对所有 token 的注意力分配—— 它要在三个候选里按比例取内容，所以这一行必须合计为 1。

按列归一化的话，就变成「所有 token 对 token 1 的关注度合计为 1」， 对每个 token 自己的取用没有意义。

代码里就是 softmax(..., dim=-1)。

第 3 行为什么完全均匀

第 3 行三个原始分数都是 1.4142，一模一样。 softmax 对相同输入给出相同输出，所以必然是 1/3。

token 3 对谁都没有偏好——它就取三个 V 的平均。

第 5 步：加权求和 V

O=AV=​0.04540.76790.3333​0.76790.04540.3333​0.18670.18670.3333​​​201​111​​=​0.27751.72251.0000​1.00001.00001.0000​​

手验第 1 行：

第1行权重 = [0.0454, 0.7679, 0.1867]
V 的三行  = [2,1], [0,1], [1,1]

第1维：0.0454×2 + 0.7679×0 + 0.1867×1 = 0.2775
第2维：0.0454×1 + 0.7679×1 + 0.1867×1 = 1.0000
第 2 维全是 1.0，不是巧合

V 的第 2 列是 [1, 1, 1]，三个一样。

那么不管权重怎么分，加权平均一定是 1.0—— 因为权重和为 1。

这可以当成一个检查「加权平均算对了没」的快捷办法。

用代码核对

import torch
import math

X = torch.tensor([[1., 0, 1, 0],
                  [0., 1, 0, 1],
                  [1., 1, 0, 0]])

Wq = torch.tensor([[1., 0], [0, 1], [1, 0], [0, 1]])
Wk = torch.tensor([[0., 1], [1, 0], [0, 1], [1, 0]])
Wv = torch.tensor([[1., 0], [0, 1], [1, 1], [0, 0]])

Q, K, V = X @ Wq, X @ Wk, X @ Wv
print(Q.tolist())          # [[2,0],[0,2],[1,1]]

scores = Q @ K.T
print(scores.tolist())     # [[0,4,2],[4,0,2],[2,2,2]]

weights = torch.softmax(scores / math.sqrt(2), dim=-1)
print(weights)

print(weights @ V)         # [[0.2775,1.0],[1.7225,1.0],[1.0,1.0]]

结果怎么读

token输出它主要取了谁的内容
1[0.2775, 1.0000]主要是 token 2（权重 0.768）
2[1.7225, 1.0000]主要是 token 1（权重 0.768）
3[1.0000, 1.0000]三个平均
这就是自注意力的输出

每个 token 都被替换成「按相关性加权的整句混合」。

token 1 的新表示里，token 2 的内容占了 77%——它已经不是原来的 token 1 了。

实际模型里通常还会加一个残差 X+O， 把原始信息和混合信息合起来。第 37 章讲。
