这正是第 37 章 Transformer 要接着做的——它完全不经过循环， 任意两个位置直接相连，「长度」不再是一个天然劣势。

看注意力权重：最直观的诊断

这是注意力独有的好处——权重可以直接读出来，不用等 BLEU。

# 生成一个句子，同时把每步的 alpha 拿回来
def greedy_with_alpha(ids, mx=25):
    with torch.no_grad():
        x = torch.tensor([ids]).to(device)
        sl = torch.tensor([len(ids)])
        out, hn = model.encoder(x, sl)
        mask = (x != 0).float()
        st = hn.squeeze(0)
        w = torch.tensor([BOS]).to(device)
        words, alphas = [], []
        for _ in range(mx):
            alpha = model.attention(st, out, mask)               # (1, T)
            ctx = torch.bmm(alpha.unsqueeze(1), out).squeeze(1)
            lg, st = model.decoder.step(w, ctx, st)
            i = int(lg.argmax(-1))
            if i == EOS:
                break
            words.append(i)
            alphas.append(alpha[0].cpu().numpy())                # 存下来
            w = torch.tensor([i]).to(device)
    return words, alphas

实测的对齐

英 i can speak english.        （5 个词）
译 我会讲英语。

  第 1 个输出词「我」  → 主要看源位置 2  (0.629)
  第 2 个输出词「会」  → 主要看源位置 3  (0.553)
  第 3 个输出词「讲」  → 主要看源位置 4  (0.568)
这就是一条对角线

输出第 1 个词看源第 2 个，第 2 个看第 3 个，第 3 个看第 4 个——稳定地往后挪一格。

因为源句第 1 个词是 i（对应「我」）， 但注意第 5 个词是句号 .，所以整体右移了一位。

模型自己学出了这个对齐，没有人告诉它。

也有对不齐的

英 drunk driving is a serious problem.
译 在美国人一样。

  第 1 个输出词 → 看源位置 2 (0.884)
  第 2 个输出词 → 看源位置 3 (0.367)
  第 3 个输出词 → 看源位置 7 (0.284)

注意第 3 步的权重只有 0.284——没有明显偏好， 七个源词分得比较平均。

这是一个可以直接用的诊断信号

权重最大值高（0.8 以上）→ 模型知道该看哪里，通常翻得对。

权重最大值低（0.3 左右）→ 模型不知道看哪，通常翻错。

所以训练中盯着平均最大权重，比只看 BLEU 更早发现问题。

推理的三个必须

#要做不做会怎样
①model.eval()dropout 还开着，同一句每次结果不同
②with torch.no_grad()白建计算图，慢且占显存
③从 <bos> 开始，遇 <eos> 停没有起点或停不下来

还有一条容易忘：mask 也要用。推理时虽然只有一个样本， 但它的源句长度就是真实长度，没有 padding——不过为了和训练一致，仍然传进去。
