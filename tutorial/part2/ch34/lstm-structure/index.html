LSTM 的结构：给记忆修一条直路

这一课在哪

上一课算清楚了：RNN 的梯度要穿过连乘，20 步之后只剩 1e-6。

这一课看 LSTM 怎么绕开这件事。它只做了一件事，但那件事改变了一切。

先问一个问题：怎么让信息「原样传下去」

假设你要把一句话的第一个词记到第 50 个词。最直接的办法是什么？

做法问题
每一步都重新算一遍「前面说了什么」这就是 RNN 的 h，算 50 次就丢光了
开一条通道，让它直接流过去不需要每步重算，也就不会丢
LSTM 的全部贡献就是第二条

它多加了一个变量 C，走一条加法的路：

Ct​=(留多少)×Ct−1​+(写多少)×(新内容)

注意那个「+」。RNN 的 h 每步都是被tanh 完全重算；C 是累加的。

那什么是「门」

上面那句里有两个括号——「留多少」和「写多少」。这两个数就是门。

设计灵感来自计算机的逻辑门：一个东西，控制「过」还是「不过」。

LSTM 的门稍微软一点：不是开/关，是「过百分之多少」。

门的值含义
0完全关闭，一点都不过
0.5过一半
1完全打开，原样通过
一个更直观的比喻：水闸

想象一条水渠，中间装了个闸门。闸门开到 30%，就只有 30% 的水流过去。

LSTM 的门就是这个闸门——只不过「开多少」是模型自己学出来的。

门为什么一定在 0 到 1 之间

因为算门的那个全连接层后面接了 sigmoid，它把任何数压到 (0, 1)。

import torch

x = torch.tensor([-5.0, -1.0, 0.0, 1.0, 5.0])
print(torch.sigmoid(x))
# tensor([0.0067, 0.2689, 0.5000, 0.7311, 0.9933])

输入 -5 出来 0.0067，输入 5 出来 0.9933，永远出不了这个范围。

这就保证了门是一个「比例」，乘上去之后不会把信息放大。

⊙ 是什么

公式里到处是 ⊙。它不是矩阵乘法， 是逐元素相乘（Hadamard 积）。

import torch

a = torch.tensor([1.0, 2.0, 3.0])
b = torch.tensor([0.5, 0.5, 0.5])

print(a * b)      # tensor([0.5000, 1.0000, 1.5000])

# 对比矩阵乘法
print(a @ b)      # tensor(3.)  —— 一个数
运算符号结果形状用途
逐元素乘⊙不变门 × 内容
矩阵乘@变了权重 × 输入

门是「同长度的向量」，一个位置控制一个位置。所以必须逐元素乘。

整个单元长什么样

沿着图从上往下读，只有三句话：

位置做什么
C 线上第一个 ×乘遗忘门——旧的 C 留多少
C 线上那个 +加新内容——这一步写多少
右侧分下来的支路C 过 tanh，再乘输出门 → 得到 h
C 和 h 的分工

C 是完整的记忆，从第一步一路攒到现在，什么都不丢。

h 是这一步要对外说出去的那一部分—— 输出门控制「露出多少」。

所以 ht​=ot​⊙tanh(Ct​)： h 不是独立的状态，它是 C 的一个受控视图。

三个门各管什么

先记个大概，下一课逐个拆：

门管什么一问
遗忘门 ft​旧的 C 留多少「以前记的还有用吗？」
输入门 it​新内容写多少「这条新信息重要吗？」
输出门 ot​h 露出多少 C「现在需要用到记忆吗？」
候选 C~t​要写的新内容本身「新信息具体是什么？」

公式合起来：

ft​it​C~t​Ct​ot​ht​​=σ(Xt​Wxf​+ht−1​Whf​+bf​)=σ(Xt​Wxi​+ht−1​Whi​+bi​)=tanh(Xt​Wxc​+ht−1​Whc​+bc​)=ft​⊙Ct−1​+it​⊙C~t​=σ(Xt​Wxo​+ht−1​Who​+bo​)=ot​⊙tanh(Ct​)​
两种等价写法

上面把 Xt​Wxf​ 和 ht−1​Whf​ 分开写。

也可以先把两者拼成一个向量 [ht−1​,xt​]， 再用一个矩阵乘。数学上完全等价，PyTorch 内部用的是后一种（更快）。

看到两种写法不要慌，是一回事。

把整个计算走一遍

光看公式还是虚的。下面用一组具体数字跑一次，每一步都算给你看。

设定

为了能手算，把维度压到最小：C 只有 2 个数。

上一步留下的：  C(t-1) = [0.8, -0.3]
上一步的隐状态：  h(t-1) = [0.5, 0.2]
这一步的输入：     x(t) = [1.0]

三个门和候选算出来的结果（假设）：
  遗忘门 f   = [0.9, 0.1]
  输入门 i   = [0.5, 0.8]
  候选   C~  = [0.6, -0.4]
  输出门 o   = [0.7, 0.9]

第 1 步：C 先是「忘一部分」

ft​⊙Ct−1​=[0.90.1​]⊙[0.8−0.3​]=[0.72−0.03​]

看这两个数：第一个位置乘 0.9，几乎全留（0.8 → 0.72）； 第二个位置乘 0.1，几乎丢光（-0.3 → -0.03）。

同一时刻，记忆的不同位置可以有不同的保留策略。这就是为什么门是一个向量而不是一个数。

第 2 步：再加进新内容

it​⊙C~t​=[0.50.8​]⊙[0.6−0.4​]=[0.30−0.32​]
Ct​=[0.72−0.03​]+[0.30−0.32​]=[1.02−0.35​]

C 从 [0.8, -0.3] 变成了 [1.02, -0.35]。

注意第一个位置变大了（0.8 → 1.02），因为新的正信息加进来了。 第二个位置几乎没变（-0.3 → -0.35），因为遗忘门几乎把它清空了， 输入门加进来的又刚好是负的。

第 3 步：从 C 里取出 h

tanh(Ct​)=[tanh(1.02)tanh(−0.35)​]=[0.770−0.336​]
ht​=ot​⊙tanh(Ct​)=[0.70.9​]⊙[0.770−0.336​]=[0.539−0.303​]
import torch

C_prev = torch.tensor([0.8, -0.3])
f = torch.tensor([0.9, 0.1])
i = torch.tensor([0.5, 0.8])
C_tilde = torch.tensor([0.6, -0.4])
o = torch.tensor([0.7, 0.9])

C = f * C_prev + i * C_tilde
h = o * torch.tanh(C)

print(C)      # tensor([ 1.0200, -0.3500])
print(h)      # tensor([ 0.5390, -0.3030])

整条链

步做什么结果
起点C(t-1)[0.8, -0.3]
①f ⊙ C(t-1)　忘一部分[0.72, -0.03]
②i ⊙ C̃　新内容[0.30, -0.32]
③相加[1.02, -0.35]
④tanh(C)[0.770, -0.336]
⑤o ⊙ 上面[0.539, -0.303]

最关键的一步：f = 1、i = 0

现在把门设成两个极端值，看会发生什么。

C_prev = torch.tensor([0.8, -0.3])
f = torch.tensor([1.0, 1.0])     # 遗忘门全开
i = torch.tensor([0.0, 0.0])     # 输入门全关
C_tilde = torch.tensor([0.6, -0.4])

C = f * C_prev + i * C_tilde
print(C)      # tensor([ 0.8000, -0.3000])    完全没变！
这两行就是 LSTM 存在的全部理由

f = 1、i = 0 时，C 原样传下去，一个数都不变。

这意味着：50 步之前的信息，可以一路原封不动传到今天。

而 RNN 做不到这一点——它的 h 每步都被 tanh 重新算， 没有任何办法「保持不变」。

梯度怎么说

把 C 的更新式对 Ct−1​ 求导（固定其它项）：

∂Ct−1​∂Ct​​=ft​

只有 ft​，没有 tanh，没有权重矩阵连乘。

那么多层连起来：

∂C1​∂Cn​​=f2​⋅f3​⋯fn​
RNNLSTM 的 C 通道
连乘的是什么权重 × tanh 导数门 f，模型自己学的
20 步之后1e-6f 全学到 0.99 就是 0.82
for f in [0.5, 0.9, 0.99]:
    print(f"f={f}:  20 步之后 = {f ** 20:.4f}")
f=0.5:  20 步之后 = 0.0000
f=0.9:  20 步之后 = 0.1216
f=0.99: 20 步之后 = 0.8179
一句话总结 LSTM

RNN 的衰减是结构决定的——tanh 导数最大 1，必然掉。

LSTM 把衰减交给模型自己决定： 需要记住就把 f 学成 0.99，需要忘就学成 0.1。

「让模型自己学该记多久」，这是 LSTM 的全部思想。

代价是什么

RNNLSTM
状态hh + C

import torch.nn as nn

rnn = nn.RNN(128, 64, batch_first=True)
lstm = nn.LSTM(128, 64, batch_first=True)

print(sum(p.numel() for p in rnn.parameters()))     # 12,416
print(sum(p.numel() for p in lstm.parameters()))    # 49,664

正好 4 倍——三个门加一个候选，四组权重Wxh​,Whh​,b。
