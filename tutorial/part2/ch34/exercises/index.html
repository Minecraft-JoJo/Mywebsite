参考答案

一、数参数
配置公式参数
RNN(100, 32)100×32 + 32×32 + 2×324,288
GRU(100, 32)3 × (100×32 + 32×32 + 2×32)12,864
LSTM(100, 32)4 × (100×32 + 32×32 + 2×32)17,152
LSTM(100, 32, 2 层)第 1 层 + 第 2 层（输入 32）25,600
LSTM(100, 32, 双向)两个方向各一份34,304

规律：

改什么参数量
RNN → GRU×3（三个门）
RNN → LSTM×4（三组门 + 候选）
1 层 → 2 层17,152 + 8,448 = 25,600，涨 49%
单向 → 双向×2

三、选网络
场景选理由
手机端实时输入预测GRU参数少、算得快，手机上每一毫秒都要省
判决书摘要（3000 字）LSTMC 通道在超长序列上更稳；3000 字远超 GRU 的舒适区
传感器 1kHzGRU 或不用循环序列极长，RNN 系列都吃力；实际多用 1D 卷积或 Transformer
教学演示RNN公式最少，一个 tanh 就完了

注意第 3 行：序列长到一定程度， 循环网络全都不合适——不是选哪个的问题。

四、找 bug
#问题后果
①没拆元组h 是 (h_n, c_n)， 直接喂 fc 报Expected input batch_size (1) to match target batch_size (64)
②双向后 fc 输入维度没翻倍输出是 2×hidden，fc 还是 hidden →mat1 and mat2 shapes cannot be multiplied
③没梯度裁剪LSTM 只解决梯度消失，不解决爆炸。 loss 可能突然变 NaN
④解码器用双向生成第 1 个词时后面的词还不存在，逻辑上就不成立。而且训练和推理不一致

① 的正确写法：

_, (h_n, c_n) = self.rnn(packed)
return self.fc(self.dropout(h_n[0]))
