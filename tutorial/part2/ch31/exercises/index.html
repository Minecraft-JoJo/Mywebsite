一、手算残差块的梯度

一个有两层线性变换的网络，输入是一个数：

x  = 2
w1 = 0.5
w2 = 0.5
L  = y          （损失就取输出本身）

两种结构：

无残差：  h = w1 * x         y = w2 * h
有残差：  h = w1 * x + x     y = w2 * h + h

验证

import torch

x = torch.tensor(2.0)

w1 = torch.tensor(0.5, requires_grad=True)
w2 = torch.tensor(0.5, requires_grad=True)

h = w1 * x
y = w2 * h
y.backward()
print("无残差", h.item(), y.item(), w1.grad.item(), w2.grad.item())

w1.grad = None
w2.grad = None

h = w1 * x + x
y = w2 * h + h
y.backward()
print("有残差", h.item(), y.item(), w1.grad.item(), w2.grad.item())

def gradient(n_layers, residual, w_value=0.5):
    weights = [torch.tensor(w_value, requires_grad=True) for _ in range(n_layers)]
    h = x
    for w in weights:
        h = w * h + (h if residual else 0)
    h.backward()
    return weights[0].grad.item()

for n in [1, 3, 10]:
    print(n, gradient(n, False), gradient(n, True))

一、手算残差块的梯度

无残差

h = 0.5 × 2       = 1
y = 0.5 × 1       = 0.5

∂L/∂w1 = ∂L/∂y · ∂y/∂h · ∂h/∂w1
       = 1 · 0.5 · 2 = 1

∂L/∂w2 = ∂L/∂y · ∂y/∂w2 = 1 · h = 1

有残差

h = 0.5 × 2 + 2     = 3
y = 0.5 × 3 + 3     = 4.5

∂h/∂w1 = x = 2                      （+x 不含 w1）
∂y/∂h  = w2 + 1 = 1.5               （+h 带一个 1）

∂L/∂w1 = 1 · 1.5 · 2 = 3

∂L/∂w2 = ∂L/∂y · h = 1 · 3 = 3

五、辨真假
#答案理由
1不准确主要作用是让「恒等映射」好学。有 BatchNorm 时梯度本来就不消失
2对每段 Residual(入,出,2) + 若干 Residual(出,出)
3错参数几乎一样（73,984 vs 75,008），但输出通道宽 4 倍
4对用了全局平均池化，不依赖输入尺寸
5对外壳都是 x + F(x)，只是 F 和归一化不同
