残差连接：一次完整的数学推导

这一课在哪

上一课确认了现象：网络到某个深度之后就上不去了。这一课不讲代码，只推数学——把一个块的输出写成式子，看看到底难在哪。

之前这一课下一课
知道了更深会更差从式子上看出为什么手算一遍验证

先把一个块写成式子

一个卷积块要做的事，就是学一个函数 H(x)。

现在问一个问题：如果最优的那个函数就是「什么都不做」，网络学得会吗？

「什么都不做」就是恒等映射 H(x) = x。 用 3×3 卷积去凑出这个函数，需要权重恰好长成某个样子。 梯度下降要精确落到那个点上——很难。

这就是退化的根源

不是没有好解，是优化器找不到它。

多出来的那些层本该学成「什么都不做」，但它们学不成， 于是把前面已经学好的结果又搅乱了。

换一个要学的东西

关键的一步：不让这个块直接学 H(x)，让它学残差。

定义：

F(x):=H(x)−x

那么块的输出就写成：

H(x)=F(x)+x
这两个式子是同一件事

F(x) = H(x) − x 和 H(x) = F(x) + x只是把同一个等式移了个项，不是两个不同的想法。

真正的区别在于：哪一边是被优化的目标。

原来网络直接输出 H(x)；现在网络输出 F(x)， 外面再手动把 x 加回去。

为什么这样就容易了

如果最优解是恒等映射 H(x) = x，那么：

F(x)=H(x)−x=x−x=0

要学的东西变成了 0。

要学的目标怎么达到难度
H(x) = x3×3 卷积的权重恰好凑出恒等映射难——必须精确
F(x) = 0权重压到 0（或很小）容易——方向明确

两条理由：

理由说明
初始点就在 0 附近权重初始化是小随机数，本来就在 0 旁边
0 是个「吸引子」权重衰减（weight decay）本来就把参数往 0 拉

学 0 只需要「不动」，学 x 需要「精确构造」。

一个具体的层：算一遍

上面的推导全是符号。这一节换成一个真的层， 把数字代进去，看残差到底改了什么。

设定

x=[12​],W=[0.50​00.5​],b=[00​]

这就是一个 nn.Linear(2, 2)，权重是「各自乘 0.5」。

前向：两种写法

写法式子结果
普通层y=Wxy=[0.5, 1.0]
残差层y=Wx+xy=[1.5, 3.0]

取一个最简单的损失：把输出的两个数加起来。

L=y1​+y2​

所以普通层 L=1.5，残差层 L=4.5。

反向：对 W 求导

先看链式法则需要什么：

∂Wij​∂L​=k∑​∂yk​∂L​⋅∂Wij​∂yk​​

因为 L=y1​+y2​，所以每个 ∂yk​∂L​=1。

而 yk​=∑j​Wkj​xj​+bk​（残差时再多加一个 xk​），所以：

∂Wij​∂yk​​={xj​0​k=ik=i​

关键：那个额外的 +xk​ 里没有 W， 所以求导时它消失了。

∂W∂L​=[x1​x1​​x2​x2​​]=[11​22​]
单层时，两种写法的 ∂L/∂W 完全一样

普通层和残差层算出来都是 [11​22​]。

那残差改变的是什么？改变的是对输入 x 的导数。

反向：对 x 求导

∂xj​∂L​=i∑​∂yi​∂L​⋅∂xj​∂yi​​

普通层里 ∂xj​∂yi​​=Wij​，所以：

普通：∂x∂L​=[0.50.5​]

残差层里，yi​=∑j​Wij​xj​+xi​， 多了一项 ∂xj​∂xi​​=δij​（i=j 时是 1，否则 0）：

∂xj​∂yi​​=Wij​+δij​
残差：∂x∂L​=[0.50.5​]+[11​]=[1.51.5​]
普通层残差层
y[0.5, 1.0][1.5, 3.0]
L1.54.5
∂L/∂W[[1,2],[1,2]][[1,2],[1,2]]
∂L/∂x[0.5, 0.5][1.5, 1.5]
这一节最重要的发现

残差没有改变 ∂L/∂W，改变的是 ∂L/∂x。

∂xj​∂L​ 多了整整 1——当这个 1 传到下一层时， 它会在下一层的 ∂W∂L​ 里起作用。

所以残差只在「堆叠」时才显出威力。一层看不出差别，二十层差 18 个数量级——这就是下一课要算的。

用 PyTorch 核对

import torch

x = torch.tensor([1.0, 2.0])
W = torch.tensor([[0.5, 0.0], [0.0, 0.5]])

# 普通层
W1 = W.clone().requires_grad_(True)
x1 = x.clone().requires_grad_(True)
y1 = W1 @ x1
L1 = y1.sum()
L1.backward()

print("普通  y =", y1.tolist())            # [0.5, 1.0]
print("      dW =", W1.grad.tolist())      # [[1.0, 2.0], [1.0, 2.0]]
print("      dx =", x1.grad.tolist())      # [0.5, 0.5]

# 残差层
W2 = W.clone().requires_grad_(True)
x2 = x.clone().requires_grad_(True)
y2 = W2 @ x2 + x2
L2 = y2.sum()
L2.backward()

print("残差  y =", y2.tolist())            # [1.5, 3.0]
print("      dW =", W2.grad.tolist())      # [[1.0, 2.0], [1.0, 2.0]]
print("      dx =", x2.grad.tolist())      # [1.5, 1.5]

再看梯度

前向是：

y=F(x)+x

对 x 求导：

∂x∂y​=∂x∂F(x)​+1

那个 +1 从 x 那一项来。它的意思是：

不管是多少层，梯度里永远有一个常数 1

反向传播时，损失对某一层的梯度是：

∂x∂L​=∂y∂L​(∂x∂F​+1)

展开：

∂x∂L​=∂y∂L​⋅∂x∂F​+∂y∂L​

第二项 ∂y∂L​ 完全不经过任何权重，原样传回去。

多层叠起来会怎样

假设堆了 n 个残差块，第 i 个块的输出是 xi+1​=Fi​(xi​)+xi​。

一直展开下去：

xn​=x0​+i=1∑n​Fi​(xi​)

这句话很重要：第 n 层的输入等于原始输入 + 所有残差之和。

所以对 x_0 求导：

∂x0​∂xn​​=1+∂x0​∂​(i=1∑n​Fi​(xi​))

前面那个 1 一直存在。不管 n 多大，它都在。

和没有残差时对比

没有残差时，每一层是 xi+1​=Fi​(xi​)，展开是连乘：

∂x0​∂xn​​=i=1∏n​∂xi​∂Fi​​
无残差有残差
形式∏i=1n​∂xi​∂Fi​​1+∂x0​∂​∑Fi​
n 很大时会怎样每个因子 < 1 就指数衰减常数 1 兜底
梯度会不会消失会不会
一个比喻

连乘就像传话游戏——每传一个人就变一次样，传十个人就面目全非。

加 1 就像每传一个人都抄一份原话给最后一个人。 哪怕中间全传歪了，原件还在。

但要小心一个说法

网上很多教程说「残差连接解决了梯度消失」。这个说法不完整。

上一节课的实验中，三个网络都用了 BatchNorm，梯度本来就没消失。 而且更深的网络训练准确率反而更高。

说法准不准
残差连接解决梯度消失不完整——有 BN 时梯度本来就不消失
残差连接让「恒等映射」容易学准确——这是原论文的论证
残差连接给梯度开了一条直通路准确——这是上面推导的结论

两件事都对，但它们解释的是不同场景： 前者在极深网络（几百层）里是决定性的，后者在任何深度都成立。
