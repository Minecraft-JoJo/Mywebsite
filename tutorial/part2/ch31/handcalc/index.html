手算一遍：残差到底改变了什么

这一课在哪

上一课推了一堆公式。这一课不用抽象符号， 用两个具体数字把每一步算出来。

算完你会看到一个很夸张的结果：20 层时梯度差 18 个数量级。

最小的网络：一个输入，两个参数

x  = 1
w1 = 0.1
w2 = 0.1

先算没有残差

h = w1 * x
y = w2 * h
L = y
h = 0.1 * 1   = 0.1
y = 0.1 * 0.1 = 0.01
L = 0.01

算 ∂w1​∂L​，用链式法则：

∂w1​∂L​​=∂y∂L​⋅∂h∂y​⋅∂w1​∂h​=1⋅w2​⋅x=0.1​

再算有残差

同样的参数，每层多加一个 h：

h = w1 * x + x
y = w2 * h + h
h = 0.1*1 + 1     = 1.1
y = 0.1*1.1 + 1.1 = 1.21
∂w1​∂h​∂h∂y​∂w1​∂L​​=x=1=w2​+1=1.1=1⋅1.1⋅1=1.1​
无残差有残差
y0.011.21
∂w1​∂L​0.11.1

差别全在这一步：

无残差：∂h∂y​有残差：∂h∂y​​=w2​=0.1=w2​+1=1.1​
一个常数 1 的威力

每经过一个残差块，梯度里多一个 +1。

w 通常小于 1，连乘会衰减；w + 1 通常大于 1，不会。

堆到 n 层

每层都用 w = 0.1，把 n 层展开：

无残差：∂w1​∂L​有残差：∂w1​∂L​​=x⋅wn−1=0.1n−1=x⋅(w+1)n−1=1.1n−1​

指数完全一样，只是底数从 w 变成了 w+1。

这正是上一课那个 +1 在多层上的样子。

跑一遍验证

import torch

x = torch.tensor(1.0)


def gradient(n_layers, residual, w_value=0.1):
    """n_layers 层，每层一个参数，返回第一层的梯度。"""
    weights = [torch.tensor(w_value, requires_grad=True) for _ in range(n_layers)]

    h = x
    for w in weights:
        if residual:
            h = w * h + h
        else:
            h = w * h

    h.backward()
    return weights[0].grad.item()


print("层数   无残差        有残差")
for n in [1, 2, 3, 5, 10, 20, 50]:
    print(f"{n:>3}   {gradient(n, False):.3e}   {gradient(n, True):.4f}")

手算和代码一行不差。

20 层时差 18 个数量级

无残差：1e-19——在 float32 里就是 0，梯度彻底没了。

有残差：6.1159——和 1 层的量级相当。

50 层时无残差直接下溢成 0.000e+00， 有残差反而涨到了 106。

换个权重看看

把 w 从 0.1 换成 0.5 和 2.0（都是 10 层）：

for w_value in [0.1, 0.5, 2.0]:
    print(f"w={w_value}  "
          f"无残差 {gradient(10, False, w_value):.3e}   "
          f"有残差 {gradient(10, True, w_value):.3e}")
w=0.1  无残差 1.000e-09   有残差 2.358e+00
w=0.5  无残差 1.953e-03   有残差 3.844e+01
w=2.0  无残差 5.120e+02   有残差 1.968e+04

对照公式：0.5⁹ = 1.953e-03，1.5⁹ = 38.44，2⁹ = 512，3⁹ = 19683。全对。

残差不是万能药

无残差的问题是连乘不稳定：w < 1 时衰减，w > 1 时爆炸。

残差把底数从 w 抬到 w+1， 让「衰减」这一侧被堵住了——w+1 永远 ≥ 0，不会小于 1 太多。

但「爆炸」那一侧没解决：w=2 时有残差反而更大。所以还需要 BatchNorm、好的初始化、梯度裁剪一起配合。

一个容易犯的错

我第一版写这一课时，把指数写成了 n 而不是 n−1， 结果 5 层写成 1.1⁵ = 1.6105，而代码给的是 1.1⁴ = 1.4641。

为什么是 n−1？因为第一层的 w1 只经过自己那一层的∂w1​∂h​=x，不经过自己的 +1。+1 来自「上一层的输出被加进下一层」，w1 之前没有层了。

公式看起来简单，指数最容易数错

这也是为什么这一课要用代码对。

手推给出结构，代码给出数字。两者对上了才算懂。
