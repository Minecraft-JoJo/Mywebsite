退化问题：更深反而更差

这一课在哪

第 29 章讲了 VGG，19 层。第 30 章讲 NiN，把全连接层换成了卷积。

再往下走，直觉是继续加深。但 19 层之后， 大家卡了整整一年——加层数不但没变好，反而变差了。

之前这一课下一课
VGG 19 层已经是极限为什么加不上去从数学上看清它

这一课一行代码都不写，只看现象和排除错误解释。

论文报告的现象

2015 年，何恺明等人在 CIFAR-10 上做了个对照实验： 用同样的方法，训一个 20 层的普通网络和一个 56 层的普通网络。

网络训练误差测试误差
20 层较低较低
56 层更高更高
盯住「训练误差」三个字

这不是过拟合。过拟合是训练误差低、测试误差高—— 模型把训练集背下来了，但没学会规律。

这里是训练误差本身就变高了。连训练集都学不好。

所以问题不在「容量不够」或「记性太好」，而在优化—— 梯度下降根本没找到好的解。

这个现象叫退化（degradation）。

我自己跑一遍

用一个真实数据集：1000 张猫狗图片（500 猫 + 500 狗）， 128×128，按 70/15/15 分。

搭三个只有深度不同的网络，各训 12 轮：

import torch.nn as nn

def plain_block(in_channels, out_channels):
    return nn.Sequential(
        nn.Conv2d(in_channels, out_channels, 3, padding=1),
        nn.ReLU(inplace=True),
    )


def make_plain(n_layers):
    layers = [plain_block(3, 32)]
    for _ in range(n_layers - 1):
        layers.append(plain_block(32, 32))
    return nn.Sequential(
        *layers,
        nn.AdaptiveAvgPool2d((1, 1)),
        nn.Flatten(),
        nn.Linear(32, 2),
    )
注意：这一版没有 BatchNorm

这是原论文的设置。下一节你会看到加了 BatchNorm 之后结果完全不同。

结果

深度参数量训练准确率测试准确率
8 层65,69870.43%69.33%
20 层176,67451.86%44.67%
32 层287,65051.86%44.67%
51.86% 是什么意思

二分类，瞎猜是 50%。51.86% 就是「全猜同一个类」。

对应地，损失一直停在 0.6925， 而 ln(2) = 0.6931。

也就是说：这两个网络根本没开始学。 参数量翻了几倍，训练准确率反而掉了 18 个点。

先排除三个错误解释

① 是不是过拟合？

不是。过拟合的表现是训练准确率高、测试低。 这里两个都低，而且训练准确率就是瞎猜水平。

② 是不是参数不够？

不是。32 层有 287,650 个参数，是 8 层（65,698）的 4.4 倍。 参数越多反而越差。

③ 是不是梯度消失？

这个最像，但不一定。同一批实验里我加了 BatchNorm 又跑了一遍：

深度加 BatchNorm 训练准确率测试准确率
8 层97.00%92.67%
20 层97.71%90.67%
32 层97.86%80.67%
这组数据推翻了一个流行说法

加了 BatchNorm 之后，22 层都没有退化—— 训练准确率不光没降，还从 97.00% 涨到 97.86%。

测试准确率下降是过拟合（数据只有 700 张），不是退化。

所以「深层网络训不动是因为梯度消失」这个说法至少不完整： BatchNorm 把梯度尺度问题解决了大半，退化依然会在某些设置下出现。

那退化的根到底在哪

回到那句最基本的话：

更深的网络，至少应该不比浅的差

为什么？因为你可以让多出来的层什么都不做—— 学成恒等映射，输入什么输出什么。

这样 56 层的输出和 20 层完全一样， 理论上限至少不低于 20 层。

但实际训练出来却更差。这说明：

候选解释能不能解释
梯度消失部分能——但加 BN 后消失不成立，退化仍在
过拟合不能——训练误差也高
参数不够不能——参数多了反而更差
「什么都不做」很难学能——下面展开

为什么「什么都不做」很难学

一个卷积块要做的事，是学一个函数 H(x)。 如果最优的 H 就是恒等映射 H(x) = x， 那么 3×3 卷积的权重必须恰好凑成那种组合。

这不是「大致往某个方向走」能到达的，是一个精确的点。

而梯度下降是在连续空间里游走，它更擅长「把东西往小了压」， 不擅长「精确调到某个值」。

下一课从这里开始

既然「学恒等映射」这么难，那就让它不用学。

下一课把这个想法写成式子，一步一步推给你看。
