下面的 assert 是 Python 的断言： 条件成立就什么也不做，不成立就当场报错。

import torch

        ...

    def __len__(self):
        ...

    def __getitem__(self, idx):
        ...

ds = CSVDataset("data.csv")

# 下面这些必须全部成立
assert len(ds) == 10
x, y = ds[0]
assert x.shape == (2,)

五、找出这段代码的三个问题

import os
from PIL import Image
from torch.utils.data import Dataset, DataLoader

class Bad(Dataset):
    def __init__(self, folder):
        self.files = os.listdir(folder)
        self.imgs = [Image.open(os.path.join(folder, f)) for f in self.files]

    def __getitem__(self, i):
        return self.imgs[i]

    def __len__(self):
        return len(self.files)

ds = Bad("./images")
loader = DataLoader(ds, batch_size=32)

六、实测像素范围

跑下面这段，填出实际数字：

from torchvision import datasets, transforms
from torch.utils.data import DataLoader

tf = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.1307,), (0.3081,)),
])

ds = datasets.MNIST("./data", train=True, download=True, transform=tf)
loader = DataLoader(ds, batch_size=64, shuffle=False)

x, y = next(iter(loader))
print(x.shape)          # ?
print(x.dtype)          # ?
print(x.min().item())   # ?
print(x.max().item())   # ?
print(y[:8])            # ?

再跑一次，去掉 Normalize，看范围变成多少。这两个范围分别是为什么？

参考答案要点

题要点
一__init__ 里 pd.read_csv(path) 存成 numpy 数组；__getitem__ 返回torch.tensor(self.X[i], dtype=torch.float32) 和torch.tensor(self.y[i], dtype=torch.long)
二391 / 50000−390×128 = 80 / 390 / 80
三3 行（4+4+2）；前两行 (4,2) (4,)，最后一行 (2,2) (2,)
四1 错（返回单个样本）／2 错（影响可复现性）／3 错（进程切换有开销）／ 4 错（验证要反映真实分布）／5 对（还做了 HWC→CHW）／6 错（是 3 个 batch，最后一个 2 行）
五① __init__ 里读了全部 10000 张图（约 1.4 GB）； ② 返回 PIL 对象，DataLoader 拼批时报错； ③ 没有 transform，也没有标签。
六(64,1,28,28)、float32、约 −0.4242、约 2.8215。 去掉 Normalize 后是 0.0 到 1.0（ToTensor 已经除过 255）。
