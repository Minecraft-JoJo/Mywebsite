反向传播走一遍

上一课是公式。这一课用一个真实的两层网络，把每个数都算一遍。

算完你会发现，backward() 一点都不神秘。

设定

网络：x(2) → Linear(2→2) → ReLU → Linear(2→1) → 输出

输入  x = [1.0, 2.0]
标签  y = 3.0
损失  MSE = (pred - y)²

前向：一步一步算

先把数据从输入推到损失，中途的每个值都记下来——反向要用。

第一层

z1 = W1·x + b1

W1 = [[0.1, 0.2],      b1 = [0.0,
      [0.3, 0.4]]             0.0]

z1[0] = 0.1×1.0 + 0.2×2.0 = 0.5
z1[1] = 0.3×1.0 + 0.4×2.0 = 1.1

z1 = [0.5, 1.1]

ReLU

a1 = relu(z1) = [0.5, 1.1]    两个都是正数，原样通过

第二层

W2 = [[0.5, 0.6]]     b2 = [0.1]

pred = 0.5×0.5 + 0.6×1.1 + 0.1
     = 0.25 + 0.66 + 0.1
     = 1.01

损失

L = (1.01 - 3.0)² = (-1.99)² = 3.9601

反向：从损失往回走

现在从损失出发，一层一层往回乘导数。每一步只用前向存下来的值。

第 1 步：对 pred 求导

L∂pred∂L​​=(pred−y)2=2(pred−y)=2×(1.01−3.0)=−3.98​

负数意思是：pred 再大一点，损失会变小。所以要把 pred 往上推。

第 2 步：对 W2 和 b2 求导

∂W2​∂L​∂b2​∂L​​=∂pred∂L​⋅a1⊤​=−3.98×[0.5, 1.1]=[−1.99, −4.378]=∂pred∂L​=−3.98​

第 3 步：传给前一层

∂a1​∂L​​=W2⊤​⋅∂pred∂L​=[[0.5], [0.6]]×(−3.98)=[−1.99, −2.388]​

第 4 步：穿过 ReLU

∂z1​∂L​​=∂a1​∂L​×1=[−1.99, −2.388]​
如果某个 z 是负的

ReLU 在那个位置的导数是 0，梯度就变成 0，那个神经元这一轮完全学不到东西。

这就是"死亡 ReLU"的由来。

第 5 步：对 W1 和 b1 求导

∂W1​∂L​∂b1​∂L​​=∂z1​∂L​⋅x⊤=[−1.99, −2.388]⊤×[1.0, 2.0]=[−1.99−2.388​−3.98−4.776​]=∂z1​∂L​=[−1.99, −2.388]​

用 PyTorch 验证

手算容易错。把同样的权重塞进 PyTorch，对一下梯度。

import torch, torch.nn as nn

torch.manual_seed(0)
net = nn.Sequential(
    nn.Linear(2, 2),
    nn.ReLU(),
    nn.Linear(2, 1),
)

# 手动设成上面那组权重
net[0].weight.data = torch.tensor([[0.1, 0.2], [0.3, 0.4]])
net[0].bias.data   = torch.tensor([0.0, 0.0])
net[2].weight.data = torch.tensor([[0.5, 0.6]])
net[2].bias.data   = torch.tensor([0.1])

x = torch.tensor([[1.0, 2.0]])
y = torch.tensor([[3.0]])

pred = net(x)
loss = ((pred - y) ** 2).mean()

print("pred", pred.item())      # 1.01
print("loss", loss.item())      # 3.9601

loss.backward()
print("W2.grad", net[2].weight.grad)   # [[-1.99, -4.378]]
print("W1.grad", net[0].weight.grad)
# [[-1.99, -3.98], [-2.388, -4.776]]

和手算完全一致。

这就是 backward 做的一切

它从损失开始，沿着前向记录的计算图往回走， 每经过一个运算就乘上那个运算的局部导数。

你手算要十几分钟，它几毫秒——而且能处理几百万参数。

四个反复出现的模式

上面每一步看起来都不一样，其实只有四种运算。记住这四个，任何网络都能手推。

环节反向公式记忆点
全连接 z=Wx+b∂W∂L​=δ⋅x⊤，∂x∂L​=W⊤⋅δ一个乘输入，一个乘转置
ReLU正数 ×1，负数 ×0只放行正数的梯度
加法梯度原样分给两边不缩放
乘法乘对方的前向值需要缓存前向结果

最后一条很关键：反向传播需要前向的中间结果。 这就是为什么训练比推理吃显存——中间激活值都得留着。

为什么叫"反向"

前向：x → z1 → a1 → pred → L        数据流从左到右
反向：L → pred → a1 → z1 → x        梯度流从右到左

前向算一遍，把中间值都存下来；反向用这些存下来的值算梯度。

一次前向 + 一次反向 = 一次训练迭代。计算量大约是前向的 2 倍。

自己实现一遍

想确认真的懂了，用纯 numpy 手写一个两层网络的反向传播：

def forward(x, W1, b1, W2, b2):
    z1 = x @ W1.T + b1
    a1 = np.maximum(z1, 0)
    pred = a1 @ W2.T + b2
    return z1, a1, pred

def backward(x, y, z1, a1, pred, W2):
    d_pred = 2 * (pred - y) / len(x)
    dW2 = d_a1 = None
    dW2 = d_pred.T @ a1
    db2 = d_pred.sum(0)
    d_a1 = d_pred @ W2
    d_z1 = d_a1 * (z1 > 0)
    dW1 = d_z1.T @ x
    db1 = d_z1.sum(0)
    return dW1, db1, dW2, db2

跑通之后和 PyTorch 的 .grad 对比，能对上就说明真的理解了。
