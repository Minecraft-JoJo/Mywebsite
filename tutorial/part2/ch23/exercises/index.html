习题

手算

用和课文一样的网络结构，换一组数：

W1 = [[1.0, 0.0],      b1 = [0.5,
      [0.0, 1.0]]            0.5]
W2 = [[1.0, 1.0]]      b2 = [0.0]

x = [2.0, 3.0]
y = 6.0
损失 = MSE
  1. 算出 z1、a1、pred、loss
  2. 算出 ∂pred∂L​
  3. 算出 ∂W2​∂L​、∂b2​∂L​
  4. 算出 ∂z1​∂L​（注意 ReLU）
  5. 算出 ∂W1​∂L​、∂b1​∂L​

跑代码验证

用 PyTorch 搭同样结构、设同样权重，确认每个梯度都对得上。

思考题

1. 如果 b1 改成 [-1.0, -1.0]

z1 会变成负数，ReLU 输出 0。这时 ∂W1​∂L​ 是多少？为什么？

2. 如果损失换成 MAE

L = |pred - y|。求 ∂pred∂L​，和 MSE 比有什么不同？

3. 为什么反向要用转置

从前向的形状推导，说明 ∂x∂L​=W⊤⋅δ 里的转置为什么必须存在。

4. 三层网络

把网络改成三层（每层 2 个神经元，中间都用 ReLU），手推一遍反向。梯度会变大还是变小？

实现

用纯 numpy 写一个两层网络的反向传播，训练 XOR 问题：

X = [[0,0], [0,1], [1,0], [1,1]]
y = [[0],   [1],   [1],   [0]]

要求：不调用任何自动求导，只用你手写的 backward。

参考答案要点

题要点
一.1z1=[2.5,3.5]，a1 相同，pred=6.0，loss=0
一.22(6.0−6.0)=0
一.3都是 0——损失已经是 0，没有梯度
三.1全是 0。ReLU 把负数的梯度挡住了，这一层学不到东西（死亡 ReLU）
三.2MAE 的导数是 sign(pred−y)，恒为 ±1，不随误差大小变化
三.3δ 形状是 (h,)，要变回 (d,) 才能传给前一层，只能乘 (d,h) 矩阵 = Wᵀ
三.4层数越多连乘越多，正常初始化下梯度会变小（梯度消失）
