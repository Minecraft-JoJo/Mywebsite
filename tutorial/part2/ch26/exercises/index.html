4. 一个卷积核够吗

参考答案

一、手算一次压缩

左上（盖住 1–3 行、1–3 列）：

1  2  3
5  6  7
9 10 11

× (1 0 -1 / 0 0 0 / -1 0 1)

= 1×1 + 2×0 + 3×(-1)
+ 5×0 + 6×0 + 7×0
+ 9×(-1) + 10×0 + 11×1
= 1 - 3 - 9 + 11 = 0

右上（1–3 行、2–4 列）：

2×1 + 4×(-1) + 10×(-1) + 12×1
= 2 - 4 - 10 + 12 = 0

左下（2–4 行、1–3 列）：

5×1 + 7×(-1) + 13×(-1) + 15×1
= 5 - 7 - 13 + 15 = 0

右下（2–4 行、2–4 列）：

6×1 + 8×(-1) + 14×(-1) + 16×1
= 6 - 8 - 14 + 16 = 0

输出是 [[0, 0], [0, 0]]。

全是 0 是有原因的：这个核做的是「左上减右下、左下加右上」的对角差分， 而输入是一个逐行递增的等差数列，四个角的两两差分恰好抵消。

这道题真正想让你看到的是：卷积核是个固定的模板， 它对某些图案强烈响应（大正数），对另一些给 0。 换个输入，输出就完全不一样。

二、改一个权重

核变成「只看中间那一格的右边两个角」——实际上只有一个 1， 所以输出就是每个 3×3 窗口的中心数。

中心是 6 的和 7 的：[[6, 7], [10, 11]]

对比：第一个核做差分（找边），这个核做取值（几乎等于原图缩小）。

这说明不同权重的卷积核在提取完全不同的东西。

五、判断对错
#答案理由
1错参数量只和通道数、核大小有关，与图像尺寸无关
2错打乱会破坏局部结构，卷积正是靠局部结构，会严重失效
3对224×224 个位置，每个 9 次乘法（准确说是 222×222 个有效位置）
4错输出通道数 = 你用了几个核，由你定
5对每卷一次边长少 (k−1)
