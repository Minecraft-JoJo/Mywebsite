三、换激活函数做对照

下面两个网络只有激活函数和池化方式不同， 其余完全一样。各训 3 轮，填表：

import torch.nn as nn

def make_net(modern=False):
    act = nn.ReLU if modern else nn.Sigmoid
    pool = nn.MaxPool2d if modern else nn.AvgPool2d

    return nn.Sequential(
        nn.Conv2d(1, 6, kernel_size=5, padding=2), act(),
        pool(kernel_size=2, stride=2),
        nn.Conv2d(6, 16, kernel_size=5), act(),
        pool(kernel_size=2, stride=2),
        nn.Flatten(),
        nn.Linear(16 * 5 * 5, 120), act(),
        nn.Linear(120, 84), act(),
        nn.Linear(84, 10),
    )

print("原版参数", sum(p.numel() for p in make_net(False).parameters()))
print("现代参数", sum(p.numel() for p in make_net(True).parameters()))

#说法对 / 错 + 理由
1LeNet 是第一个卷积神经网络
2LeNet 用 ReLU 是因为当年只有 ReLU

参考答案

一、推形状（32×32 输入）
层输出怎么算
C16@32×3232 + 4 − 5 + 1
S26@16×1632 ÷ 2
C316@12×1216 − 5 + 1
S416@6×612 ÷ 2
Flatten57616 × 6 × 6

不能直接用 Linear(400, 120)。要改成 Linear(576, 120)。

报错是：mat1 and mat2 shapes cannot be multiplied (128x576 and 400x120)。

576 = 16×6×6，400 = 16×5×5。差在第二次卷积之后。

二、算参数（32×32 版本）
层权重偏置合计
Conv2d(1,6,5,p=2)6×1×25 = 1506156
Conv2d(6,16,5)16×6×25 = 2,400162,416
Linear(576,120)576×120 = 69,12012069,240
Linear(120,84)10,0808410,164
Linear(84,10)84010850
合计82,826

比 28×28 版本多了 21,120 个参数 （82,826 − 61,706）。

全在 Linear(576,120) 那一层： 576×120 − 400×120 = 69,120 − 48,000 = 21,120。

输入边长从 28 涨到 32，拉平后 400 → 576， 全连接第一层就跟着涨。

三问的答案：

#答案
1完全一样。激活函数和池化方式都不带参数—— sigmoid/ReLU 是逐元素函数，AvgPool/MaxPool 只做比较或平均
23.89 个百分点（94.42% → 98.31%）
3sigmoid 的导数最大 0.25，ReLU 是 1。 三层 sigmoid 连乘 0.25³ = 0.0156， ReLU 是 1。梯度差 64 倍，所以 sigmoid 学得慢
四、辨真假
#答案理由
1错LeNet 是「第一个成功训练并大规模应用」的， 卷积的想法在 1980 年代就有了
2错正好相反：用 sigmoid 是因为当年还没有 ReLU。 原文说「虽然 ReLU 和最大汇聚层更有效，但它们在 90 年代还没有出现」
3错padding 只补 0，卷积核大小不变，参数不变
4错卷积的每个参数要在图上扫几百次，参数少省的是显存不是时间
5对拉平之后空间结构没了，只能接全连接。 要用卷积必须保持四维形状
