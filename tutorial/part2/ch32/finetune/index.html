微调：冻结与训练

这一课在哪

上一课说了要「冻结大部分层」。这一课讲具体怎么冻。

这一课只给局部代码——每一段单独讲清楚。 完整能跑的版本在下一课。

requires_grad：一个开关

每个参数张量上有个布尔标记 requires_grad。 它决定反向传播时要不要给这个参数算梯度。

import torch
import torch.nn as nn

layer = nn.Linear(4, 2)
print(layer.weight.requires_grad)      # True

layer.weight.requires_grad = False
print(layer.weight.requires_grad)      # False
requires_grad反向传播时optimizer.step()
True算梯度，存在 .grad会更新
False跳过，.grad 是 None不动
冻结 = 把 requires_grad 设成 False

没有别的机制。整个「冻结」就是这一个布尔值。

参数还在、还能做前向计算，只是不再被梯度下降改动。

冻结整个网络

import torchvision.models as models

net = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)

for param in net.parameters():
    param.requires_grad = False

数一下还剩多少可训练的：

def count_trainable(model):
    return sum(p.numel() for p in model.parameters() if p.requires_grad)

print(count_trainable(net))     # 0

0。现在整个网络都冻住了，训它不会有任何变化。

换掉最后一层

冻完再把分类头换掉。新建的层默认 requires_grad=True， 所以换完就自动是可训练的：

import torch.nn as nn

net.fc = nn.Linear(in_features=512, out_features=2)

print(count_trainable(net))     # 1,026

1,026 是怎么来的：

512 × 2 + 2 = 1,026
↑权重      ↑偏置
参数量占比
整个网络11,177,538100%
可训练1,0260.0092%
一万分之一

可训练参数只占总量的 0.0092%。

这就是为什么几百张图就够——要学的只有 1026 个数。

冻哪些层

ResNet 的结构是五段。四种常见的冻结方案：

方案冻训可训练参数
A 只训分类头全部卷积fc1,026
B 训最后一段stem~layer3layer4 + fc约 839 万
C 训后两段stem~layer2layer3 + layer4 + fc约 1,048 万
D 全训不冻全部11,177,538

怎么按段冻结

# 先全部冻住
for param in net.parameters():
    param.requires_grad = False

# 再单独解冻要训的段
for param in net.layer4.parameters():
    param.requires_grad = True

for param in net.fc.parameters():
    param.requires_grad = True

先全冻、再解冻，比「一个个冻」安全——不会漏。

优化器只能收可训练的参数

这一点很容易错：

# ✗ 错：把冻结的参数也给了优化器
optimizer = torch.optim.Adam(net.parameters(), lr=1e-3)

# ✓ 对：只给可训练的
trainable = [p for p in net.parameters() if p.requires_grad]
optimizer = torch.optim.Adam(trainable, lr=1e-3)
传错了会怎样

不会报错，但优化器里多了一堆永远梯度为 None 的参数， 白占显存。

更麻烦的是：有些优化器（比如带动量的）会给这些参数建状态， 显存占用翻倍。

而且用 len(optimizer.param_groups[0]['params']) 检查数量时会对不上，调试很难。

学习率要调小

预训练的权重已经很好，不要用大步长去踹它。

训练什么建议学习率
只训分类头（新层）1e-3
微调已有层1e-4 ~ 1e-5

更细的做法是给不同部分不同的学习率：

optimizer = torch.optim.Adam([
    {"params": net.fc.parameters(),      "lr": 1e-3},   # 新层，大步长
    {"params": net.layer4.parameters(),  "lr": 1e-4},   # 微调，小步长
])
为什么新层可以用大步长

fc 是随机初始化的，本来就什么都不会，需要快点学。

layer4 已经学得不错了，只需要小幅调整。

用一个学习率的话，要么新层学太慢，要么旧层被踹坏。

标准化必须用 ImageNet 的

这是个隐蔽的坑：预训练时用的是一套特定的均值和方差，推理和微调时必须用同一套。

from torchvision import transforms

# ImageNet 的统计量，不是你自己数据的
mean = (0.485, 0.456, 0.406)
std  = (0.229, 0.224, 0.225)

transform = transforms.Compose([
    transforms.Resize((224, 224)),
    transforms.ToTensor(),
    transforms.Normalize(mean=mean, std=std),
])
用错标准化的后果

不会报错，但准确率会明显下降。

因为网络内部的激活值分布和你微调时喂进去的对不上， BatchNorm 跑出来的结果就不是训练时那个意思了。

而且输入尺寸也要 224×224——预训练就是在这个尺寸上学的。

完整流程

import torch.nn as nn
import torchvision.models as models

# ① 拿预训练模型
net = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)

# ② 全部冻住
for param in net.parameters():
    param.requires_grad = False

# ③ 换分类头（新层默认可训练）
net.fc = nn.Linear(in_features=512, out_features=2)

# ④ 优化器只收可训练的
trainable = [p for p in net.parameters() if p.requires_grad]
optimizer = torch.optim.Adam(trainable, lr=1e-3)

# ⑤ 损失函数
loss_fn = nn.CrossEntropyLoss()

# 之后就是普通的训练循环了
