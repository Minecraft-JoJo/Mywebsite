习题

四道题：数参数、选冻结方案、踩坑、辨真假。

一、数可训练参数

ResNet18，最后分类头换成 10 类。四种冻结方案，填表：

方案冻结可训练参数占总参数
A全部卷积
Bstem~layer3
Cstem~layer2
D不冻
import torch.nn as nn
import torchvision.models as models

def count_trainable(model):
    return sum(p.numel() for p in model.parameters() if p.requires_grad)

def build(freeze_upto):
    net = models.resnet18(weights=models.ResNet18_Weights.DEFAULT)
    net.fc = nn.Linear(in_features=512, out_features=10)

    for param in net.parameters():
        param.requires_grad = False

    sections = ["layer4", "layer3", "layer2", "layer1", "none"]

    if freeze_upto != "all":
        start = sections.index(freeze_upto)
        for name in ["layer4", "layer3", "layer2", "layer1"][:start]:
            for param in getattr(net, name).parameters():
                param.requires_grad = True

    for param in net.fc.parameters():
        param.requires_grad = True
    return net

for name in ["all", "layer4", "layer3", "none"]:
    net = build(name)
    print(name, count_trainable(net))

四、辨真假

#说法对 / 错 + 理由
1迁移学习只能用于图像任务
2冻结之后参数会被删除，模型变小
3数据越少，越应该多训几层
4换了 net.fc 之后，新层默认是可训练的
5预训练模型必须用 224×224 的输入

参考答案

一、数可训练参数
方案可训练占比
A 只训头5,1300.046%
B 训 layer48,395,78675.1%
C 训 layer3+410,491,91493.9%
D 全训11,181,642100%

A 的 5,130 是 512 × 10 + 10。

注意 B 一下子跳到 75%——因为 layer4 通道最多（512）， 参数是通道数的平方。

二、选方案
场景选理由
猫狗 700 张A数据极少 + 和 ImageNet 极像（猫狗就是 ImageNet 的类别）
罕见皮肤病 300 张A 或 C数据太少只能 A；但如果显微镜图和自然图像差太远， 低层特征也不适用，可以试 C 并加重正则
商品识别 5 万张D数据足够多，全训不会过拟合，效果最好
X 光 2 万张C 或 D数据够，但域差很大，需要让更多层适应新数据

规律：数据越多、域差越大，就该训越多层。

三、三个错
#问题后果
①没冻结可以跑，但等于全训，700 张图会过拟合
②优化器收了冻结的参数不会报错，但多占显存；而且optimizer.param_groups[0]['params'] 数量对不上， 很难调试
③尺寸和标准化都错了应该是 224×224 和 ImageNet 的 (0.485, 0.456, 0.406) /(0.229, 0.224, 0.225)。 用错不会报错，但准确率明显掉

①③ 是「不报错但效果差」的那类，最难查。跑之前先对一遍。

四、辨真假
#答案理由
1错NLP 里更常见——BERT、GPT 的预训练权重就是标准起点
2错参数还在、还能前向计算，只是不再更新
3错正好相反：数据少要少训几层，否则过拟合
4对新建的 nn.Linear 默认 requires_grad=True
5基本对严格说可以换尺寸（有全局池化），但和预训练时的分布差太远，效果会掉。建议保持 224
