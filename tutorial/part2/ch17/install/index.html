conda：CPU 还是 GPU

这一课不讲深度学习，只讲一件事：把 PyTorch 装对。

装错了不会报错，只会白等。这部分内容适合读者在真正开始训练之前先确认一遍。

为什么用 conda，不用系统 Python

系统的 Python 只有一份。你在这个项目里装了某个版本，另一个项目需要另一个版本，就打架了。

conda 解决的是"隔离"问题：每个项目一个独立环境，各自有 Python 和包。

方案隔离能管非 Python 依赖适合
系统 Python + pip❌ 全局❌不推荐
venv✅❌ 只管 Python 包小项目、纯 Python
conda✅✅ 能装 CUDA、编译器深度学习
conda 的关键优势

深度学习依赖一堆非 Python 的二进制库：CUDA runtime、cuDNN、MKL。

venv 管不了这些，conda 能。

装 Miniconda，然后建一个环境

别装 Anaconda（几个 GB、塞一堆用不上的包）。装 Miniconda，只有 conda 和 Python。

  1. 搜 "miniconda download"，选 Windows 64-bit
  2. 安装时勾选 "Add to PATH"（不勾的话后面要在 Anaconda Prompt 里操作）
  3. 装完开一个新终端，输入 conda --version 验证
PowerShell 里 conda 不能用的处理

PowerShell 默认禁止运行脚本，conda activate 会报无法加载文件...因为在此系统上禁止运行脚本。

开管理员 PowerShell 跑一次：

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

建环境

conda create -n dl python=3.11 -y
conda activate dl

三件事值得说：

做法为什么
-n dl 给环境起名别用 base。base 坏了要重装 conda
指定 python=3.11不指定会拿最新版，可能还没有对应的 torch 轮子
-y跳过确认

常用环境管理命令：

conda env list                 # 有哪些环境，* 是当前
conda activate dl             # 进入
conda deactivate              # 退出
conda remove -n dl --all      # 整个删掉
conda list                    # 当前环境装了哪些包

CPU 版和 GPU 版的真正区别

这不是一个开关

PyTorch 的 GPU 版和 CPU 版是两个不同的安装包，里面编进去的代码不一样。

GPU 版内置了 CUDA 和 cuDNN 的二进制，体积大好几倍；CPU 版根本没有这些代码， 就算你有显卡也用不上。

所以"装了 CPU 版再改个设置就能用 GPU"——不可能，必须重装。

先确认你的机器能不能用 GPU

开终端输入：

nvidia-smi

能出下面这种表格就说明有 NVIDIA 显卡和驱动：

+-----------------------------------------------------------------------------+
| NVIDIA-SMI 595.97       Driver Version: 595.97       CUDA Version: 13.1     |
|-------------------------------+----------------------+----------------------+
|   0  NVIDIA GeForce RTX 5060 ...  |   00000000:01:00.0  |                  |
+-------------------------------+----------------------+----------------------+

没有这个命令、或者报"不是内部或外部命令"，有两种情况：

情况怎么办
没有 NVIDIA 显卡（Intel / AMD 核显）装 CPU 版
有 N 卡但没装驱动去 NVIDIA 官网下驱动，装完重启

看懂右上角的 CUDA Version

nvidia-smi 右上角那个 CUDA Version 是驱动支持的最高版本， 不是你已经装的版本。

这个数字是上限，不是要求

驱动显示 CUDA 13.1，意味着你能跑 CUDA 13.1 及以下的所有 PyTorch。

装 cu128（CUDA 12.8）的包完全没问题——向下兼容。

反过来不行：驱动只支持到 11.8，装 cu128 的包会报CUDA driver version is insufficient。

三条安装命令

① CPU 版（没有 N 卡时）

pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
必须加 index-url

不加的话，pip install torch 在 Windows 上默认装的是 CPU 版， 看起来装成功了，但 torch.cuda.is_available() 是 False。

这是最常见的坑。

② GPU 版（用 pip）

去 pytorch.org 首页，用那个选择器生成命令。或者直接写：

pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128

把 cu128 换成你需要的 CUDA 版本（cu121 / cu124 / cu126 / cu128…）。

③ GPU 版（用 conda）

conda install pytorch torchvision pytorch-cuda=12.8 -c pytorch -c nvidia
pipconda
速度快慢（依赖求解）
体积小大
CUDA 版本控制靠 --index-url 选靠 pytorch-cuda= 选
推荐✅ 官方现在主推需要 cuDNN 等配套库时

国内下载慢

两个办法，选一个：

# 办法一：用清华镜像装（注意：镜像上的 torch 通常只有 CPU 版）
pip install torch torchvision -i https://pypi.tuna.tsinghua.edu.cn/simple

# 办法二：开代理，直接用官方源（推荐，能拿到 GPU 版）
# 在终端里临时设置
set HTTPS_PROXY=http://127.0.0.1:7890
镜像站的坑

国内镜像同步的主要是 PyPI 上的包，而 PyPI 上的 torch 在 Windows 上就是 CPU 版。

想装 GPU 版，必须走 download.pytorch.org。要么开代理，要么忍着慢。

验证

装完在环境里跑这一段：

import torch

print(torch.__version__)              # 2.11.0+cu128  ← 有 +cu 就是 GPU 版
print(torch.cuda.is_available())      # True
print(torch.cuda.get_device_name(0))  # NVIDIA GeForce RTX 5060 Laptop GPU

x = torch.randn(1000, 1000, device="cuda")
print((x @ x).shape)                  # torch.Size([1000, 1000])
看版本号里的后缀

2.11.0+cu128 —— 有 +cu 就是 GPU 版，cu128 表示编译时用的 CUDA 12.8。

2.11.0+cpu 或干脆没有后缀 —— CPU 版。

出错对照表

现象原因解决
is_available() 是 False，版本号没有 +cu装成了 CPU 版卸载重装，加 --index-url
CUDA driver version is insufficient驱动太老，撑不住这个 CUDA 版本更新 NVIDIA 驱动，或装更低 cu 版本的包
nvidia-smi 找不到没驱动 / 没 N 卡装驱动，或改用 CPU 版
CUDA out of memory显存不够（不是装错）调小 batch_size，见下面
Torch not compiled with CUDA enabled同第一条，CPU 版重装 GPU 版
警告 CUDA initialization: ...驱动加载失败重启，或重装驱动

装完要花多少空间

实测一个装了 GPU 版 torch 的环境：

项目体积
torch 包本身4211 MB
整个环境目录9.4 GB
为什么这么大

GPU 版把 CUDA runtime、cuDNN、cuBLAS、各种算子的预编译内核全打进去了。

CPU 版大约 200 MB，差 20 倍。

所以装之前先看看 C 盘剩多少，必要时把环境建在别的盘。

把环境记录下来

环境装好后导出，换机器或重装时能一键还原：

conda env export > environment.yml
conda env create -f environment.yml

更轻量的做法是只记 pip 包：

pip freeze > requirements.txt
pip install -r requirements.txt
requirements.txt 里的 torch 要写清楚

pip freeze 记下来的是 torch==2.11.0+cu128， 但别人 pip install -r 时会去 PyPI 找 CPU 版，装不上。

在文件开头加一行，明确来源：

--index-url https://download.pytorch.org/whl/cu128
torch==2.11.0+cu128

检查清单

✓检查项
□装了 Miniconda，不是 Anaconda
□建了独立环境（-n dl），不是用 base
□指定了 Python 版本
□跑过 nvidia-smi，知道自己有没有 N 卡
□版本号里有 +cu（如果要用 GPU）
□torch.cuda.is_available() 是 True
□在 GPU 上跑通过一次矩阵乘
□导出了 environment.yml 或 requirements.txt
