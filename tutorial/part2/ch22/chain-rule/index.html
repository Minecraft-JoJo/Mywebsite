链式法则

这一课是数学。但它只讲一件事，而且是整个深度学习唯一必需的数学。

一、导数是"变化率"

y = f(x) 的导数 dy/dx 回答：x 增加一点点，y 变多少。

函数导数
y = 3x3
y = x²2x
y = x³3x²
y = eˣeˣ
y = ln x1/x
y = c（常数）0

二、复合函数

神经网络就是一层套一层：

x → [乘2] → a → [加1] → b → [平方] → y

a = 2x
b = a + 1
y = b²

问：x 变一点，y 变多少？

链式法则说：把每一步的导数乘起来。

dy/dx = dy/db · db/da · da/dx
      = 2b  ·  1   ·  2
      = 4b
      = 4(2x + 1)
就这一条

复合函数的导数 = 各层导数的乘积。

深度学习里所有梯度都是这么算出来的，没有别的。

验证一下

x = 3 时：a = 6，b = 7，y = 49。

公式给 dy/dx = 4 × 7 = 28。

直观验证：x 从 3 变到 3.001，a 变 0.002，b 变 0.002，y 变7.002² − 49 ≈ 0.028。Δy/Δx = 0.028/0.001 = 28。✓

三、两个函数的组合规则

加法

y = f(x) + g(x)     →   dy/dx = f'(x) + g'(x)

各算各的，加起来。

乘法

y = f(x) · g(x)     →   dy/dx = f'g + fg'

链式

y = f(g(x))        →   dy/dx = f'(g(x)) · g'(x)

四、换成偏导

神经网络有很多参数，不是只有一个 x。

对其中一个求导、把其他当常数，叫偏导，写成 ∂。

L = (w₁x₁ + w₂x₂ - y)²

∂L/∂w₁ = 2(w₁x₁ + w₂x₂ - y) · x₁
∂L/∂w₂ = 2(w₁x₁ + w₂x₂ - y) · x₂

注意只有最后那一项不同：对 w₁ 求导时挂上 x₁， 对 w₂ 求导时挂上 x₂。

规律

某个权重对损失的"责任"，和它乘的那个输入成正比。

输入是 0 的权重，梯度就是 0——它这次没参与，也就学不到东西。

五、矩阵形式

一层网络：

z = Wx + b
a = relu(z)
L = loss(a, y)

反向传播的形状是：

∂L/∂W = (∂L/∂z) · xᵀ
∂L/∂b = ∂L/∂z
∂L/∂x = Wᵀ · (∂L/∂z)
式子含义
∂L/∂W = δ · xᵀ权重的梯度 = 这一层的误差 × 输入
∂L/∂x = Wᵀ · δ传给前一层的误差 = 权重转置 × 误差
这两行就是反向传播的全部

前向是 z = Wx，反向是 δ·xᵀ 和 Wᵀ·δ。

一个用输入，一个用转置。矩阵乘法在前向和反向各用一次。

六、为什么用 Wᵀ

因为形状要对上。

前向：x (d,)  ×  W (h, d)  →  z (h,)

反向：δ (h,) 要变成 (d,) 才能传给前一层
      所以 δ 乘一个 (d, h) 的矩阵 = Wᵀ

形状对不上时，先怀疑是不是漏了转置。

七、激活函数的导数

函数导数特点
ReLU: max(0,x)x>0 ? 1 : 0最好算
Sigmoidσ(x)(1−σ(x))最大 0.25，容易梯度消失
Tanh1 − tanh²(x)最大 1
ReLU 的导数有多简单

大于 0 就是 1，小于 0 就是 0。乘法都不用做。

这就是 ReLU 取代 sigmoid 的主要原因之一。

八、梯度消失从哪来

看链式法则的连乘：

∂L/∂x₁ = ∂L/∂xₙ · ∂xₙ/∂xₙ₋₁ · ... · ∂x₂/∂x₁
        = 很多个数相乘

如果每一层导数都是 0.25（sigmoid 的最大值），10 层之后：

0.25¹⁰ ≈ 0.00000095

梯度几乎没了。前面的层完全学不到东西。

这就是深度网络的第一个难关

ReLU 的导数要么 0 要么 1，连乘不会衰减那么快——这是它救活深度学习的直接原因。

残差连接（第 29 章）是另一个解法：给梯度开一条直通的路。
