优化器

损失算出梯度，优化器拿梯度改参数。这一课看它到底怎么改。

一、最朴素的更新

# 手写梯度下降
for p in model.parameters():
    p.data -= lr * p.grad

这就是 SGD（随机梯度下降）的全部。

用 PyTorch 的写法：

opt = torch.optim.SGD(model.parameters(), lr=0.01)

opt.zero_grad()
loss.backward()
opt.step()          # 等价于上面那个循环
优化器拿着参数对象的引用

构造时传 model.parameters()，之后它一直持有这些参数。

所以 step() 不需要再告诉你改哪些参数。

也因此：模型换了，优化器必须重建。旧的优化器还指着旧参数。

二、为什么要有优化器，手写不行吗

因为现代优化器要存"历史状态"——动量、梯度平方的滑动平均。 这些东西每个参数都要存一份，手写很啰嗦。

优化器存了什么显存
SGD无（可选动量）1×
SGD(momentum=0.9)一份动量2×
Adam动量 + 梯度平方3×

参数本身占 1 份，Adam 要额外占 2 份。一亿参数的模型，Adam 光状态就吃 800 MB。

三、常用优化器

优化器特点什么时候用
SGD(lr, momentum=0.9)简单，泛化好CV 任务、追求最终精度
Adam(lr)自适应，开箱好用默认选择、NLP、小数据
AdamW(lr, weight_decay)Adam + 正确的权重衰减现在最常用
RMSpropAdam 的前身少见
torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.9)
torch.optim.Adam(model.parameters(), lr=1e-3)
torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-2)
学习率数量级不同

SGD 常用 0.1 / 0.01；Adam 系列常用 1e-3。

把 SGD 的学习率直接搬到 Adam 上，会直接发散。

四、Adam 和 AdamW 的区别

Adam(weight_decay=0.01) 把权重衰减混进了梯度里，和不衰减的效果不一样。

AdamW 把衰减单独拿出来做，效果符合预期。

能用 AdamW 就用它，别用 Adam(weight_decay=...)。

五、参数分组：不同层用不同学习率

迁移学习的标准写法：

opt = torch.optim.AdamW([
    {"params": model.features.parameters(), "lr": 1e-4},   # 预训练部分，小
    {"params": model.head.parameters(),     "lr": 1e-3},   # 新加的层，大
], lr=1e-3)

预训练的部分已经很好了，动太多会破坏；新加的层要从零学，步子可以大。

六、学习率调度器

sched = torch.optim.lr_scheduler.StepLR(opt, step_size=10, gamma=0.1)
# 每 10 个 epoch，lr 乘 0.1

sched = torch.optim.lr_scheduler.CosineAnnealingLR(opt, T_max=100)
# 余弦缓慢下降，现在很常用

for epoch in range(epochs):
    train_one_epoch()
    sched.step()      # 每轮调一次

sched.step() 的位置有讲究：在 optimizer.step() 之后。

七、三个必守的规矩

for x, y in loader:
    pred = model(x)
    loss = loss_fn(pred, y)

    opt.zero_grad()      # 1. 清零（必须在 backward 前）
    loss.backward()      # 2. 求梯度
    opt.step()           # 3. 更新参数
规矩不遵守会怎样
zero_grad() 在 backward() 前梯度累加，越训越离谱
backward() 在 step() 前用旧梯度更新
优化器在把模型搬到 GPU 之后建参数不一致
模型要先 .to(device) 再建优化器
model = model.to(device)          # 先搬
opt = torch.optim.Adam(model.parameters(), lr=1e-3)   # 再建

顺序反了会报 can't optimize a non-leaf Tensor 或静默失效。

八、怎么判断学习率对了

现象说明
损失不降太小
损失震荡、突然变大太大
损失先降后升太大，已经跳过最优点
损失平稳下降合适
损失变 nan明显太大
