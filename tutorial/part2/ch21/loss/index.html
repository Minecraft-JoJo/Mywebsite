损失函数

损失是模型唯一能看见的东西。它决定了模型往哪个方向学。

一、任务决定损失

任务输出损失
多分类C 个分数CrossEntropyLoss
二分类1 个分数BCEWithLogitsLoss
回归1 个实数MSELoss / L1Loss

二、交叉熵

loss_fn = nn.CrossEntropyLoss()

logits = torch.randn(64, 10)          # 模型原始输出，没经过 softmax
target = torch.randint(0, 10, (64,))  # 正确答案，0-9 的整数

loss = loss_fn(logits, target)        # 一个标量
输入是 logits，不是概率

CrossEntropyLoss 内部做了 log_softmax。

所以模型最后一层不要加 softmax，加了等于做两次，结果全错。

这是最常见的实现错误之一。

它到底在算什么

# 数学上等价于：
# 1. softmax 把分数变成概率
probs = torch.softmax(logits, dim=1)
# 2. 取正确类别的概率，取对数，取负
loss = -torch.log(probs[range(len(target)), target]).mean()
预测正确类别的概率损失
0.990.01
0.900.11
0.500.69
0.102.30
0.014.61

猜得越离谱，惩罚越重，而且是指数级的。这就是交叉熵比 MSE 更适合分类的原因。

三、二分类

loss_fn = nn.BCEWithLogitsLoss()

logits = torch.randn(64, 1)             # 一个分数
target = torch.randint(0, 2, (64, 1)).float()   # 必须是 float！

loss = loss_fn(logits, target)
三个必须对齐的地方

① 目标要 .float()（BCE 要求浮点）

② 输出和目标的形状要一致，都是 (N, 1)

③ 是 BCEWithLogitsLoss，不是 BCELoss——后者要求你先过 sigmoid

四、回归

nn.MSELoss()          # 均方误差，对离群点敏感
nn.L1Loss()           # 绝对误差，对离群点稳健
nn.SmoothL1Loss()     # 两者折中（Huber）

五、一个 batch 上有多种写法

loss_fn = nn.CrossEntropyLoss()

# 默认：对一个 batch 内所有样本取平均
loss = loss_fn(logits, target)

# 不平均，返回每个样本的损失
loss_each = loss_fn(logits, target, reduction="none")    # shape (64,)

# 求和
loss_sum = loss_fn(logits, target, reduction="sum")

reduction="none" 很有用：想知道哪些样本错得最离谱时， 按损失排序看前几个。

六、类别不平衡

# 正类只占 1%，给它 99 倍的权重
weights = torch.tensor([1.0, 99.0])
loss_fn = nn.CrossEntropyLoss(weight=weights)

另一种做法是 nn.CrossEntropyLoss(label_smoothing=0.1)， 不让他把概率压到 1.0，能缓解过拟合。

七、损失突然变成 nan

原因检查
学习率太大调小 10 倍试试
数据里有 nantorch.isnan(x).any()
log(0)要用 logits 版损失，别手写 log
梯度爆炸加 clip_grad_norm_
除以 0检查自定义 loss 里的分母

八、训练的第一步永远是看损失

# 未训练时，10 分类的交叉熵应该是 ln(10) ≈ 2.30
print(loss_fn(model(x), y).item())
这个数字是基准

10 分类，随机猜的概率是 10%，损失 -ln(0.1) = 2.30。

一开始损失远大于 2.30 → 初始化或数据有问题。

一开始就接近 0 → 数据泄漏，标签混进特征了。
