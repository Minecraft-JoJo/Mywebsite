把 VGG 跑起来

这一课在哪

上一课讲了三条规矩。这一课把它们写成代码。

你会看到一个对比：AlexNet 要五十多行，VGG 二十行就够。

先抽一个块

import torch
import torch.nn as nn

def conv_block(in_channels, out_channels):
    return nn.Sequential(
        nn.Conv2d(in_channels, out_channels, kernel_size=3, padding=1),
        nn.BatchNorm2d(out_channels),
        nn.ReLU(inplace=True),
    )
原版 VGG 没有 BatchNorm

2014 年的论文里没有 BN——它 2015 年才被提出。

这里加上它，因为不加的话 13 层卷积很难训。

这就是「原始论文」和「现代实现」的差距，读论文时要留意。

padding=1 配 kernel_size=3， 输出尺寸等于输入——这就是上一课那条规矩①。

用列表描述结构

上一课那张表可以直接写成一个列表：数字是通道数，"M" 是池化。

整个网络

class VGG(nn.Module):
    def __init__(self, config, num_classes=1000, in_channels=3):
        super().__init__()

        layers = []
        channels = in_channels

        for item in config:
            if item == "M":
                layers.append(nn.MaxPool2d(kernel_size=2, stride=2))
            else:
                layers.append(conv_block(channels, item))
                channels = item

        self.features = nn.Sequential(*layers)

        self.classifier = nn.Sequential(
            nn.AdaptiveAvgPool2d((7, 7)),
            nn.Flatten(),
            nn.Linear(in_features=512 * 7 * 7, out_features=4096),
            nn.ReLU(inplace=True),
            nn.Dropout(p=0.5),
            nn.Linear(in_features=4096, out_features=4096),
            nn.ReLU(inplace=True),
            nn.Dropout(p=0.5),
            nn.Linear(in_features=4096, out_features=num_classes),
        )

    def forward(self, x):
        features = self.features(x)
        logits = self.classifier(features)
        return logits

三处要停一下

写法为什么
channels = item每建完一个块，更新「下一层的输入通道」
nn.Sequential(*layers)星号必需。不加是把整个列表当成一层
AdaptiveAvgPool2d((7, 7))保证不管输入多大，后面都能接 512*7*7

小图版

VGG 本来要 224×224。用 MNIST 的话，通道和尺寸都要缩。

# 通道数减半，专给 32×32 的小图用
VGG_SMALL_CONFIG = [32, "M", 64, "M", 128, 128, "M", 256, 256, "M", 256, 256, "M"]

class VGGSmall(nn.Module):
    def __init__(self, config, num_classes=10, in_channels=1):
        super().__init__()

        layers = []
        channels = in_channels
        for item in config:
            if item == "M":
                layers.append(nn.MaxPool2d(kernel_size=2, stride=2))
            else:
                layers.append(conv_block(channels, item))
                channels = item

        self.features = nn.Sequential(*layers)

        self.classifier = nn.Sequential(
            nn.AdaptiveAvgPool2d((1, 1)),
            nn.Flatten(),
            nn.Linear(in_features=channels, out_features=1024),
            nn.ReLU(inplace=True),
            nn.Dropout(p=0.4),
            nn.Linear(in_features=1024, out_features=num_classes),
        )

    def forward(self, x):
        features = self.features(x)
        logits = self.classifier(features)
        return logits
32×32 的图经过 5 次池化会怎样

32 → 16 → 8 → 4 → 2 → 1。

第五次池化时输入已经是 2×2，池完正好 1×1。再多一次就没了，所以小图最多撑 5 个池化段。

通道减半也是同一个道理：32×32 撑不起 512 个通道，参数会浪费在过拟合上。

print(sum(p.numel() for p in model.parameters()))    # 2,581,834

loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)

for epoch in range(1, 7):
    model.train()
    for images, labels in train_loader:
        images = images.to(device)
        labels = labels.to(device)

        logits = model(images)
        loss = loss_fn(logits, labels)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

    model.eval()
    val_loss, seen, correct = 0.0, 0, 0
    with torch.no_grad():
        for images, labels in val_loader:
            images = images.to(device)
            labels = labels.to(device)

            logits = model(images)
            val_loss += loss_fn(logits, labels).item() * labels.size(0)
            seen += labels.size(0)
            correct += (logits.argmax(dim=1) == labels).sum().item()

    print(
        f"{epoch}   val_loss {val_loss/seen:.4f}   "
        f"val_acc {100*correct/seen:.2f}%"
    )

VGG11 小图版 258 万，AlexNet 小图版 378 万。

但 VGG 层数更多（8 层 vs 5 层），而且每层都配了 BatchNorm。

不是「参数多就强」，是「结构对就强」。

第 1 轮差 5 个点，为什么

AlexNetVGG11
BatchNorm没有每层都有
第一个卷积11×11 步长 43×3 步长 1
第 1 轮就能到92.03%97.30%

主因是 BatchNorm。它把每层输出拉回均值 0、方差 1， 后面的层不用再追着前面层的变化跑。

次因是 11×11 步长 4 在小图上太伤—— 32×32 的图一上来就被砍成 8×8。
