nn.RNN 与完整模型

这一课在哪

上一课手写了一遍，看清了内部。这一课用官方实现搭出真正能用的模型。

整个模型只有三层：

索引  →  embedding  →  RNN  →  取最后一步  →  全连接  →  2 类

nn.RNN 的参数

import torch.nn as nn

rnn = nn.RNN(
    input_size=128,       # 每个时间步输入的维度
    hidden_size=64,       # 隐藏状态 h 的维度
    num_layers=1,         # 堆几层
    batch_first=True,     # 输入形状是 (B, L, D) 而不是 (L, B, D)
    bidirectional=False,  # 是否双向
)
参数作用这里为什么这么设
input_size每个词的向量维度等于 embedding 的 embedding_dim
hidden_sizeh 有多长64 够用，大了容易过拟合
num_layers堆几层 RNN先 1 层，够用再加
batch_first形状约定一定设 True，否则和 DataLoader 对不上
bidirectional要不要反向再跑一遍情感分析可以用，先关着
batch_first 默认是 False

PyTorch 的默认约定是 (seq_len, batch, feature)—— 这是从早期版本留下来的。

但 DataLoader 吐出来的是 (batch, seq_len, feature)。

不设 batch_first=True 不会报错， 但模型会把「第 1 个样本的第 1 个词」当成「第 1 个词的第 1 个样本」， 结果全错。

它的输入输出

import torch

x = torch.randn(32, 20, 128)      # 32 个句子，每句 20 个字，每字 128 维
out, h_n = rnn(x)

print(out.shape)      # torch.Size([32, 20, 64])
print(h_n.shape)      # torch.Size([1, 32, 64])
返回值形状是什么
out(32, 20, 64)每一步的 h
h_n(1, 32, 64)最后一步的 h，第一维是层数

h_n[0] 和 out[:, -1, :] 是同一个东西。 情感分析只要最后一个，所以用 h_n[0] 就行。

完整模型

import torch
import torch.nn as nn

class SentimentRNN(nn.Module):
    def __init__(self, vocab_size, embed_dim=128, hidden_size=64,
                 num_layers=1, num_classes=2, dropout=0.3):
        super().__init__()

        self.embedding = nn.Embedding(
            num_embeddings=vocab_size,
            embedding_dim=embed_dim,
            padding_idx=0,
        )

        self.rnn = nn.RNN(
            input_size=embed_dim,
            hidden_size=hidden_size,
            num_layers=num_layers,
            batch_first=True,
        )

        self.dropout = nn.Dropout(dropout)
        self.fc = nn.Linear(hidden_size, num_classes)

    def forward(self, x):
        # x: (batch, seq_len) 的整数索引
        embedded = self.embedding(x)          # (B, L, 128)
        out, h_n = self.rnn(embedded)         # out (B, L, 64), h_n (1, B, 64)

        last = h_n[0]                         # (B, 64) —— 只看最后一步
        last = self.dropout(last)
        logits = self.fc(last)                # (B, 2)
        return logits

逐层形状

层输入输出
输入—(32, 20) 整数
embedding(32, 20)(32, 20, 128)
rnn(32, 20, 128)out (32,20,64) / h_n (1,32,64)
取 h_n[0](1, 32, 64)(32, 64)
fc(32, 64)(32, 2)

三个细节

① padding_idx=0 很重要

self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)

它保证第 0 行（<pad>）永远是全 0，且不更新。

RNN 读到 0 向量时，W_xh @ 0 = 0，等于「这一位什么都没输入」。

② 只用最后一步

last = h_n[0]        # ✓ 用这个
# last = out[:, -1, :]   # 等价，但 h_n 更直观

但这里有个问题：如果最后一堆都是 padding，h_n 是「读完所有 padding 之后」的状态。

padding 会污染最后一步

句子 A 是真长度 10，补到 20。第 20 步的 h 是读完了 10 个真字 + 10 个 0 之后的结果。

tanh 会不断把状态往某处推，10 步 padding 足以改变它。

标准解法是 pack_padded_sequence，下一课讲。 这一课先用「取真长度位置的 h」这个简单办法。

简单版的正确做法：

def forward(self, x, lengths):
    embedded = self.embedding(x)
    out, _ = self.rnn(embedded)

    # 按每个样本的真实长度取最后一步
    batch = x.size(0)
    idx = (lengths - 1).view(batch, 1, 1).expand(batch, 1, out.size(2))
    last = out.gather(1, idx).squeeze(1)

    return self.fc(self.dropout(last))

③ dropout 放在哪

位置效果
embedding 之后随机把一些词向量置 0，像丢了几个字
RNN 之后、fc 之前随机掐掉一部分 h 的维度
RNN 内部（nn.RNN(dropout=)）只在多层时生效，单层无效

这里放在 RNN 之后——最常用、最安全的位置。

数参数

VOCAB_SIZE = 3000

model = SentimentRNN(vocab_size=VOCAB_SIZE)
total = sum(p.numel() for p in model.parameters())
print(f"{total:,}")
层计算参数
embedding3000 × 128384,000
rnn（w_xh）64 × 1288,192
rnn（w_hh）64 × 644,096
rnn（bias ×2）64 × 2128
fc64 × 2 + 2130
合计396,546
embedding 占了 97%

384,000 ÷ 396,546 = 96.8%

RNN 本身只有 12,416 个参数——权重共享的结果， 和句子长度完全无关。

这也解释了为什么词表大小是第一位的：V 减半，参数就减半。
