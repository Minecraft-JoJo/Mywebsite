附录 A　机器学习项目的完整流程

这一节是把整个流程一次看全，不要求现在全部理解。后面每章会拆开讲其中一步。

A.1 训练循环

代码 
flowchart TD
  A["参数 w, b（先随便猜）"] --> B["前向：用当前参数算预测"]
  B --> C["损失：预测和真值差多少"]
  C --> D["梯度：往哪个方向调能变小"]
  D --> E["更新：w ← w − 学习率 × 梯度"]
  E -->|"重复几百次"| B

前向

\hat{y}^{(i)} = w x^{(i)} + b

损失（均方误差）

L(w, b) = \frac{1}{m} \sum_{i=1}^{m} \left( \hat{y}^{(i)} - y^{(i)} \right)^2

梯度：损失对参数的导数。\dfrac{\partial L}{\partial w} > 0 表示 w 增大会让损失增大，所以要让 w 减小——这就是更新时减去梯度的原因。

更新

w \leftarrow w - \alpha \frac{\partial L}{\partial w}, \qquad b \leftarrow b - \alpha \frac{\partial L}{\partial b}

\alpha 是学习率，决定每步迈多大。

训练只是第 8 步。

flowchart TD

  B --> C["3 探索与清洗"]
  C --> D["4 特征工程"]

A.3 跑一遍

任务：猜出 y = 2x + 1 这条线，数据带噪声。

python code/ch01_loss_goes_down.py

预期输出（CPU 约 1 秒）：

epoch   0   loss=  2.0940   w= 0.5690   b= 0.9455
epoch   1   loss=  0.6202   w= 0.9940   b= 0.9606
epoch   2   loss=  0.3121   w= 1.2931   b= 0.9719
epoch   5   loss=  0.0464   w= 1.7560   b= 0.9893
epoch  10   loss=  0.0107   w= 1.9610   b= 0.9971
epoch  20   loss=  0.0096   w= 2.0026   b= 0.9987
epoch  50   loss=  0.0096   w= 2.0038   b= 0.9987
epoch 200   loss=  0.0096   w= 2.0038   b= 0.9987

最终 w = 2.0038   （真值 2.0）
最终 b = 0.9987   （真值 1.0）
loss 从 2.0940 降到 0.009589

三点：

  1. loss 在下降。2.09 → 0.0096。它不降，模型就没在学。
  2. 参数逼近真值。真值 w=2, b=1，训完 2.0038 / 0.9987，差一点因为数据里有噪声。
  3. loss 停在 0.0096 不是 bug。噪声标准差 0.1，方差 0.01，任何模型都不可能低于它，这叫噪声地板。
